## 3. 케이스 대장을 어디에 두는가

사용자 요건: **케이스는 앞으로 계속 쓴다.** 손으로 동기화하는 안은 이 프로젝트에서 썩는다(규칙 8이 존재하는 이유).

**채택 — 「코드가 대장, 문서는 생성물, 어긋나면 테스트가 깨진다」 3단** (E §7):

| 단 | 무엇 |
|:--:|---|
| ① | `QaCases.cs`가 케이스 ID·설명·잡는 회귀의 **유일 선언** |
| ② | C#은 `[Property("CaseId", …)]`, 파이썬은 `check(…, case="E-18")`로 **기존 문법 안에서** 부착 |
| ③ | `QaCaseRegistryTests`가 **선언↔구현 드리프트**와 생성 문서 불일치를 **테스트로 깨뜨린다** |

이 프로젝트가 이미 쓰는 전수 검사 관용구(`TestGetUnwiredSfxIds`)와 같은 모양이라 새 개념이 0이다.
