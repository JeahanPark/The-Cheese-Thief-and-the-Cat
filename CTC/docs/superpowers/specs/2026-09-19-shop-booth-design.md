## 0. 왜 바꾸나

지금 상점은 **주황 원반 + 빵 선반**이다. 규칙(원 안에서만 산다)은 읽히지만 「가게」로 안 읽히고, 판 안에서 아무 일도 안 한다.
가게를 **살아 있는 것**으로 만든다 — 안에 쥐 점원이 있고, 고양이가 오면 겁먹고 철문을 내린다.

> **상점은 고양이가 오면 닫힌다.** 쥐는 사러 가기 전에 고양이를 떼어 놓아야 하고, 고양이는 상점 앞을 지켜 경제를 막을 수 있다.

## 1. 모양

| 부분 | 모양 |
|---|---|
| 몸통 | 나무 상자 가게(가로 1.4 · 깊이 1.0 · 높이 1.15m) — 창고 맵의 나무 궤짝과 같은 결 |
| 창구 | 앞면 가로 창(0.95 × 0.42m) · 아래에 판매대(앞으로 0.18m 튀어나온 판) |
| 차양 | 창구 위 줄무늬 천(치즈색·빨강) — 멀리서도 「가게」로 읽힌다 |
| 간판 | 지붕 위 치즈 한 조각(`M_Cheese`) — 상점 자리를 멀리서 알린다 |
| 철문 | 창구 위 셔터 상자에서 내려오는 **골판 철판**(짙은 회색) |
| 점원 | 쥐(팩 쥐 모델, **밤색 털**) — 창구 안에서 바깥을 본다 |

- 원반(반경 3m, 사는 자리)은 그대로다 — 원 안 어디서든 산다(지금과 같다).
- **몸통은 막힌다**(상자 콜라이더) — 창구 앞에 서서 산다. 원반 안이 넓어(반경 3m) 몸통을 빙 둘러도 산다.
  봇은 원반 가운데가 아니라 **창구 앞**(`ShopSpot.FrontPoint`)으로 간다.
- 부스는 **맵 가운데를 본다**(창구가 방 안쪽으로 난다).

## 2. 철문

| 항목 | 규칙 |
|---|---|
| 닫힘 | 고양이가 상점 중심 **5m**(`ShopShutterCloseMeters`) 안 — **살금살금이면 2.5m**(`ShopShutterSneakMeters`). 점원도 발소리를 듣는다 |
| 열림 | 모든 고양이가 **6.5m**(`ShopShutterOpenMeters`) 밖에 **1.5초**(`ShopShutterReopenSeconds`) 머물면 |
| 판정 | 서버가 0.2초마다 본다 · 복제값 하나(`ShopShutter.Closed`) — 전 클라가 같은 값을 보고 각자 애니메이션 |
| 연출 | 닫힘 0.35초(쾅 — 가속) · 열림 0.8초(드르륵 — 감속) · 소리 한 번 · 점원이 움츠린다(`Fear`) |
| 강아지 | 반응하지 않는다(제3세력은 상점을 노리지 않는다) |

## 3. 닫힌 동안

- **그 상점에서 못 산다** — `TechDeny.ShopClosed` 「철문이 닫혔다 — 고양이가 근처에 있다」.
- 열려 있던 **상점 팝업은 닫힌다**(맞았을 때와 같은 자리 — `ShopPopupLogic.ShouldClose`).
- 이미 산 기술을 **쓰는** 것은 상관없다(요새·창고 설치 · 대시 등).
- 봇은 닫힌 상점을 목적지로 고르지 않는다.

## 4. 점원

- 평소 `Idle_A`, 누가 이 상점에서 사면 끄덕인다(`Clicked` — 구매 이펙트 `BuyCoins`가 원반 안에서 터질 때),
  철문이 닫히면 움츠린다(`Fear` — 반복) · 열리면 다시 선다.
- 네트워크 없음 — 철문 복제값과 구매 이펙트(전 클라에서 이미 도는 것)만 본다.

## 5. 정보 설계 (§11)

철문이 내려오는 것은 **「고양이가 5m 안에 있다」는 새 신호**다 — 사용자 지시라 의도된 정보다.
대신 **살금살금 고양이에게는 늦게 반응한다**(2.5m) — 고양이에게도 수가 있다(상점 앞 매복).
멀리서 철문 상태를 보는 것은 막지 않는다(보이는 것은 보인다). 미니맵에는 올리지 않는다.

## 6. 정한 것 — 바꿀 수 있다

| 정한 것 | 다른 길 | 바꾸는 법 |
|---|---|---|
| 닫힌 동안 **못 산다** | 연출만(살 수 있음) | `ShopController.CanBuyNow`의 `ShopClosed` 한 줄 |
| 살금살금은 2.5m에서야 닫힌다 | 걸음과 무관하게 5m | CSV `ShopShutterSneakMeters` = 5 |
| 몸통이 막힌다 | 지나다닌다(지금 원반처럼) | `ShopBoothBuilder`의 몸통 콜라이더 |

## 7. 구조

| 조각 | 종류 | 책임 |
|---|---|---|
| `ShopShutterLogic` | 순수 static | 경보 반경(살금살금 포함) · 닫힘/열림 전이(히스테리시스·재개방 대기) · 철문 내려온 정도(시간표) |
| `ShopShutter` | NetworkBehaviour(상점 자리) | 서버 0.2초 판정 · 복제값 `Closed` · 클라 연출(철문·소리) · `AnyOpenContains` |
| `ShopKeeper` | Component(점원) | `Closed` 구독 → `Fear`/`Idle_A` · `FxPlayer.Played(BuyCoins)` → `Clicked` |
| `ShopBoothBuilder` | Editor | 부스 메시·머티리얼·점원을 상점 자리 프리팹에 굽는다 |
| `ShopController` | 기존 수정 | `CanBuyNow` — 원 안인데 닫혔으면 `ShopClosed` |
| `ShopPopup` | 기존 수정 | 닫히면 팝업을 닫는다 · 카드에 사유 |
| `BotAgent` | 기존 수정 | 열린 상점 · 창구 앞으로 간다 |

## 9. 잘라낸 것

- **점원에게 말 걸기·대화**: 상점 팝업(E)이 그 역할이다.
- **철문 부수기**(고양이가 철문을 때려 연다): 부술 수 있으면 「닫힘」의 뜻이 흐려진다.
- **닫힌 상점 미니맵 표시**: 멀리서 고양이 위치를 흘린다.
- **새 소리**: 소리는 유료 ElevenLabs로 다시 만들기로 보류 중이다 — 철문 소리는 요새 설치음을 임시로 쓴다.

## 10. 구현하며 바뀐 것

| 항목 | 기획 | 구현 | 왜 |
|---|---|---|---|
| 가게 전등 | 없음 | 창구 안 점광원 + 전구(`ShopLamp`) — **철문을 따라 꺼진다** | 밤 맵에서 창구 안이 새까매 점원이 안 보였다. 꺼진 불은 멀리서도 「닫았다」로 읽힌다 |
| 차양 높이 | 창구 위 | 창구 윗변보다 위로 올림(뒤 0.97 · 앞 0.88m) | 낮게 두니 카메라 높이에서 창구와 점원을 가렸다 |
| 핫바 안내 | — | 원 안인데 닫혔으면 모드 줄 「E = 상점」 자리에 「철문 닫힘」 · 빈 칸 「E로 산다」 거둠 | E가 말없이 안 먹으면 고장으로 보인다 |

| 창구 앞 요새 | — | 막지 않는다(즉발 요새는 원래 자리를 안 가린다 — 벽 곁도 같다) | 부스를 파고들 뿐 규칙이 깨지지 않는다 |
