# 쥐 사격 클립 — 설계

작성 2026-09-12 · 상태: 승인됨 (사용자 승인 2026-09-12)

> **이것이 「모션 0」을 깨는 첫 작업이다.** 계획 2c로 오래 대기하던 항목이고,
> [블렌더 파이프라인](2026-09-12-blender-animation-pipeline-design.md)이 초록이 되어 착수한다.

---

## 1. 왜 사격이 첫 클립인가

| | |
|---|---|
| **가장 많이 보인다** | 쥐의 좌클릭이다. 한 판에 수십 번 나온다 |
| **가장 안 맞는다** | 지금 팩의 `Attack`(물어뜯기)이 나간다. 새총·기관총인데 무는 동작이다 |
| **정보를 안 만든다** | §2 참조 |
| **한 개다** | 파이프라인을 처음 쓰는 작업이라 **하나로 검증**하고 늘린다 |

나머지 액티브 셋(대시=`Roll` · 끈끈이=`Bounce` · 요새=`Jump` · 광분=`Spin`)은 그럭저럭
맞거나 덜 보인다. 이번엔 안 건드린다.

---

## 2. 정보 설계 확인 (기획서 §11)

기획서의 기준선은 **「이미 있는 것을 그림으로 바꾸는 것은 되고, 없던 것을 만드는 것은 안 된다」**이다.

| | 판정 |
|---|---|
| **사격 동작** | **된다.** 사격은 이미 **소리가 나고**(`SlingshotFire`·`MachinegunFire`) **예광선이 보인다**(`TracerRpc`). 동작을 바꾸는 것은 이미 있는 사건의 **그림을 고치는 것**이지 새 채널이 아니다 |
| ~~티어별로 다른 동작~~ | **기각.** 새총·기관총·긴 총열을 동작으로 구분하면 고양이가 **「저 쥐가 어느 티어인가」**를 알게 된다 — 없던 정보다. **세 티어가 같은 클립을 쓴다** |
| ~~패시브 테크를 몸에 드러내기~~ | **기각.** 「저 쥐가 뭘 샀나」는 없던 정보다. 동공 축소를 기각한 것과 같은 줄이다 |

두 번째 줄이 이 문서에서 실제로 무언가를 **막은** 지점이다. 소리는 이미 티어마다 다르지만
그건 **거리로 감쇠하는 채널**이고, 동작은 **보이면 확정**이라 성질이 다르다.

## 3. 클립 명세

### 제약

| | |
|---|---|
| 뼈 | 11개 — `root · body · head · ear.L/R · leg.F.L/R · leg.B.L/R · tail.01/02` |
| **팔이 없다** | 네발 짐승이다. **앞다리가 곧 손**이라, 쏘려면 뒷다리로 서야 한다 |
| 예산 | **10프레임 / 24fps = 0.4167초** — 팩 클립 20개가 전부 이 예산이다 |
| 이름 | `Shoot` |

### 프레임

건드리는 뼈는 **6개**(`body` · `leg.F.L` · `leg.F.R` · `head` · `tail.01` · `tail.02`).
`root`와 뒷다리는 건드리지 않는다 — 발이 미끄러져 보인다.

| 프레임 | body | 앞다리 L/R | head | tail | 뜻 |
|:--:|---|---|---|---|---|
| 0 | 0° | 바닥 | 정면 | 아래 | 시작(대기와 이어짐) |
| 2 | **−25°** | 앞으로 들어올림 | 조준 | 뒤로 균형 | 일어서며 겨눔 |
| **4** | **−35°** | **위로 튕김** | 살짝 젖힘 | 확 뒤로 | **발사 — 반동** |
| 6 | −20° | 내려옴 | 정면 | 복귀 | 되돌아옴 |
| 10 | 0° | 바닥 | 정면 | 아래 | 대기로 |

각도는 **출발점**이지 정답이 아니다. 눈으로 보고 굴린다(§5).

**0과 10이 같은 포즈여야 한다** — 원샷이 끝나고 이동 상태로 돌아갈 때 튀지 않게.

## 4. 온몸이냐 상체만이냐 — 온몸으로 간다

원샷은 `PlayerAnimationDriver.PlayOneShot`이 **온몸을 덮는다**. 달리다 쏘면 0.3초 동안
뒷다리로 서 버린다.

| | |
|---|---|
| **A. 온몸 (채택)** | 기존 원샷 여섯과 **일관**된다. `Attack`도 이미 같은 성질이다. 추가 배선 0 |
| B. 상체만 마스크 | 자연스럽다. 대신 `AvatarMask` 경로 함정이 있다 — 경로 기준이 Animator라 어긋나도 **에러 없이 0개를 켠다**(CLAUDE.md 기록) |

**A로 간다.** 첫 클립에서 새 위험을 같이 들이지 않는다. 어색하면 그때 B로 간다 —
**전환 조건은 「달리면서 쏘는 장면을 보고 사람이 어색하다고 말하는 것」**이다. 추측으로
미리 B를 만들지 않는다.

## 5. 만드는 방법 — 손으로 포즈, 스크립트로 굽기

```
mouse.blend에서 손으로 포즈 5개
        │
        ├─ 눈으로 보며 각도를 굴린다  ←─┐
        │                              │
        ▼                              │
커브를 tools/blender/clips/shoot.py로 덤프
        │                              │
        ▼                              │
export_clips.py → FBX → 유니티          │
        │                              │
        ▼                              │
Tools/CTC/Dev/클립 미리보기 렌더 ────────┘
```

**왜 손이 먼저인가**: 뼈 6개 × 5포즈면 숫자로 찍는 것보다 보면서 잡는 게 빠르고 낫다.
**왜 그다음 스크립트인가**: `.blend`는 바이너리라 diff가 안 된다. 커브를 숫자로 덤프해 두면
리뷰·되돌리기가 되고 명령 한 줄로 재생성된다. **한쪽으로만 문이 열려 있다** — 손으로 만든
것을 스크립트로 굽는 것은 되고, 반대는 안 된다.

덤프 도구(`tools/blender/dump_action.py`)는 이 작업에서 같이 만든다.

## 6. 배선

| 어디 | 무엇 |
|---|---|
| `CTC_Mouse_Clips.fbx.meta` | `clipAnimations`에 `takeName: Rig\|Shoot` 블록 추가 (블렌더가 테이크 이름에 접두를 강제한다) |
| `AC_Mouse.controller` | `Shoot` 상태 추가. **`AC_Cat`은 안 건드린다** — 고양이는 안 쏜다 |
| `AnimationStateLogic` | `public const string Shoot = "Shoot";` + `All` 배열에 추가 |
| `MousePopgun.cs:186` | `AnimationStateLogic.Attack` → `.Shoot` (`TracerRpc` 안, 전 클라이언트) |

**상수를 반드시 거친다.** `CrossFadeInFixedTime`은 없는 상태 이름을 받아도 **에러도 경고도
내지 않고** 아무 일도 안 한다. 문자열을 호출부에 흘리면 오타가 조용히 죽은 원샷이 된다.

`ATTACK_ANIM_SECONDS`의 값은 그대로 쓴다 — 클립 길이(0.4167초)에 맞춰 조정이 필요하면
그때 재고 고친다.

## 7. 완료 기준

| | |
|---|---|
| `Shoot`이 `AC_Mouse`에 있고 `AnimationStateLogic.All`에 있다 | EditMode가 철자를 묶는다(기존 패턴) |
| 쏘면 `PlayerAnimationDriver.PlayingState`가 `Shoot`이다 | **「시켰다」가 아니라 「돌고 있다」를 본다** — 조용히 죽은 원샷을 잡는 유일한 방법 |
| `Probe Clip Parity`가 기존 19클립에 대해 여전히 `같다` | **새 클립을 더하면서 있던 것을 안 깼다** |
| 미리보기 렌더로 5프레임이 의도대로 보인다 | 수치가 맞는데 눈이 이상하면 재는 방법이 틀린 것 |
| `shoot.py`로 클립을 재생성하면 같은 결과 | 손 작업이 숫자로 남았다 |
| 고양이는 아무것도 안 바뀐다 | `AC_Cat` 무변경 |

## 8. 범위 밖

| | |
|---|---|

## 9. 위험

| | 완화 |
|---|---|
| 포즈가 팩 톤과 안 맞는다 | 10프레임 예산을 지키고, **기존 클립 옆에 나란히 렌더**해 비교 |
| 달리며 쏠 때 어색하다 | §4의 전환 조건. 미리 만들지 않는다 |
| `.meta`의 `clipAnimations`가 재생성되며 이름이 되돌아간다 | `RoundTrippedClip_IsNamedWalk_NotRigPipeWalk`가 이미 그때 빨개진다. `Shoot`도 같은 검사에 포함시킨다 |
| 클립을 더하다 기존 19개를 깬다 | 완료 기준 3번이 그걸 본다 |
