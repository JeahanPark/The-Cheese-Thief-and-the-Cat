# 미니맵 기획 (2026-09-08)

## 0. 왜 지금인가

테크 v3가 **목적지 경제**를 만들었다. 쥐는 이제 치즈를 캐는 데 그치지 않고
**상점 자리까지 걸어가야** 사고 키운다. 창고는 120×120이고 상점은 4곳이다.

지도가 없으면 이 경제는 「길을 아는 사람이 이긴다」가 된다 — 판을 거듭할수록
좋아지는 게 실력이 아니라 **암기**다. 스팀 2시간(≈7판) 동안 새 빌드를 시도하게
만들려면, 길은 처음부터 알려 주고 **배분을 고민하게** 해야 한다.

> 미니맵은 레이더가 아니라 **창고 평면도**다.
> 답해 주는 질문: 「나 어디 · 상점 어디 · 내 창고 어디」.
> 답하지 않는 질문: 「적 어디」.

## 1. 용어

| 말 | 뜻 |
|---|---|
| 지형 | 선반·궤짝 벽·경계 — `MapLayout`이 든 사각형들 |
| 마커 | 지형 위에 찍히는 점(상점·치즈·내 구조물) |
| 발견 | 그 마커에 **일정 거리 안까지 가 본 적이 있다**(클라 전용 기억, 판마다 초기화) |
| 전체 고정 | 맵 전체를 한 장에 담고 **회전하지 않는다**(북 고정) |

## 2. 무엇을 보여 주는가 — 비대칭 표

| 요소 | 쥐 | 고양이 | 이유 |
|---|:--:|:--:|---|
| 지형·경계 | ○ | ○ | 길찾기는 정보가 아니다 |
| 내 위치·바라보는 방향 | ○ | ○ | |
| **상점 자리 4** | ○ | ○ | 쥐는 가야 하고 고양이는 막아야 한다 — **여기서 만난다** |
| 치즈 매장지 14 | **발견분만** | ✕ | 처음엔 탐색, 두 번째부턴 동선. 고양이가 알면 매복이 공짜다 |
| 내 창고·내 요새 | ○(내 것만) | ✕ | 「째고 나서 어디로 돌아가나」 |

| 고양이 위치 | ✕ | — | 스텔스 핵심 — `StatusHud`가 고양이 HP를 숨기는 것과 같은 판단 |
| 벽감 11 | ✕ | ✕ | 숨을 자리를 찾는 게 재미다 |

**한 줄 원칙**: 미니맵은 *지형과 내 것*만 그린다. 남은 절대 안 그린다.

## 3. 화면

- 자리: **좌상단**. 우상단(상태)·하단(핫바·능력바)·좌하단(채팅)·상단중앙(타이머)은 이미 찼다.
- 상시 표시, 작게. `StatusHud`의 「상시는 얇게」와 같은 태도다.
- **전체 고정 · 북 고정**(따라다니지도, 돌지도 않는다).
  창고는 존 구조라 전체가 한눈에 들어와야 「저기가 상점」이 읽힌다. 돌리면 손으로 그린
  평면도의 랜드마크가 무너진다.
- 확대/전체화면 **없음** — 새 화면 0(테크 v3 제약)을 지킨다.

## 5. 어떻게 그리는가

지형은 **`MapLayout`을 읽어 판 시작에 텍스처 한 장을 굽는다.** 매 프레임 그리는 건
마커 위치뿐이라 실질 비용이 0이다.

버린 안:
- **실시간 오소 카메라 → RenderTexture**: URP 렌더 패스가 매 프레임 하나 는다.
  에디터 3인 MPPM이 이미 무겁다.
- **에디터에서 미리 구운 그림**: 손 배치 창고에만 맞다. 격자 맵(`Large01`)은 시드로
  지어지므로 못 굽는다.

`MapLayout`은 두 종류를 다 든다 — 손 배치는 `Props`(창고 77개), 절차 생성은
`Rooms`+`Corridors`. 둘 다 사각형이라 같은 코드로 칠해진다.

**최소 두께 2px** — 120 m를 256 px에 넣으면 얇은 선반이 사라진다.

## 6. 색

`UiPalette` 단독 출처를 따른다. 새 색을 만들지 않는다.

| 것 | 색 |
|---|---|
| 바닥 | `Slot` |
| 지형(선반·궤짝) | `Line` |
| 경계 | `Groove` |
| 상점 | `Accent`(치즈 노랑) |
| 치즈 매장지(발견분) | `AccentSoft` |
| 내 창고·요새 | `Good` |
| 나 | `TextOn` 삼각형(바라보는 방향) |

## 8. 만들지 않는 것 (기록)

- 팀 쥐 표시 — 2절의 이유. **밸런스 다이얼로 뒤집을 수 있게** 판정을 순수 함수에 둔다.
- 소리 핑(발소리가 난 자리) — 「예민한 귀」에 눈에 보이는 채널을 주는 자연스러운 확장이지만,
  적 정보라 2절 원칙을 건드린다. **별도 기획으로 판단한다.**
- 전체화면 지도·확대·핑 찍기 — 새 화면 0.
