## 0. 왜 바꾸나

지금 용사는 **숫자만 크다** — HP가 두 배고 총이 조금 세다. 판에서 「용사가 있다」가 드러나는 순간이 없고,
쥐 여덟이 다 같은 일(쏘고 도망)을 한다. 표를 주운 사람에게 **다른 역할**을 준다:

> **용사는 딜러가 아니라 고양이를 멈춰 세우는 벽이다.**

피해가 약한 것은 의도다. 용사 혼자 고양이를 잡지 못하고, **스턴 0.8초 동안 동료가 쏜다.**

## 1. 바뀌는 것

| | 지금 | 바뀐 뒤 |
|---|---|---|
| 기본 공격 | 총(딱총·새총·기관총) | **칼** — 총은 아예 못 쓴다 |
| 공격 주기 | 총 티어에 따라 0.15~0.8초 | **3초** |
| 한 방 | 5~12 (용사 배율로 7.5~18) | **20** (용사 배율로 **30**) |
| 부가 효과 | 없음 | **맞은 대상 0.8초 스턴** |
| 액티브 | 대시(사면) | **무적** — Space · 3초 · 쿨 10초 |
| HP ×2 | 유지 | 유지 |
| 겉모습 | 그대로 | **변신 연출(칼을 뽑아 하늘을 찌른다)** · 휘두를 때 칼이 보인다 — §10 |

**총 테크는 여전히 살 수 있지만 쏘지는 못한다** — 깡패와 같은 규칙(`TechDeny.GangNoGun`)으로 **구매를 막는다**.
후추 탄도 같이 막힌다(총알이 없으므로 의미가 없다).

**대시는 못 쓴다.** Space가 무적으로 바뀌므로, 이미 산 대시는 칸을 차지한 채 잠긴다 — 살 때 막는다(위와 같은 규칙).

## 2. 정체가 드러난다 (의도)

깡패는 **2단계가 열릴 때까지** 겉모습이 안 바뀐다 — 누가 깡패인지 숨기는 게 그 직업의 전부라서다.
용사는 반대다. **표를 밟는 순간 칼을 꺼내고**, 그 모습이 고양이에게도 보인다.

- 고양이는 「저 쥐를 먼저 잡을지, 피할지」를 판단할 수 있다.
- 쥐들은 용사 뒤에 붙는다 — 스턴이 도는 자리가 안전지대가 된다.

## 4. 스턴 — 신규 공통 시스템

지금 이 게임에는 「멈춤」이 없다(끈끈이는 감속이다). 새로 만들되 **한 곳**에만 만든다.

| 항목 | 규칙 |
|---|---|
| 막는 것 | 이동 · 공격 · 액티브 · 임명 전부 (깡패 변신 잠금 `GangTransformLock`과 같은 판정 자리) |
| 대상 | 고양이 · 강아지 · 쥐 — 진영을 가리지 않는다. 2단계에서 용사가 깡패를 멈출 수 있다 |
| 겹침 | 다시 맞으면 **시간이 갱신**된다(더해지지 않는다) |
| 표시 | 맞은 쪽 머리 위에 별이 도는 이펙트. 본인 화면에는 화면 가장자리 흰 테두리 |
| 소유 | 서버가 건다(`Stun` 컴포넌트 · 복제값 `StunUntil`). 클라는 그 값을 보고 입력을 막는다 |
| 봇 | 같은 값을 본다 — 스턴 중에는 `BotAgent`가 아무 명령도 안 낸다 |

## 5. 연출 (사용자 지시 ⑥)

### 5-1. 변신 — 표를 밟는 순간 (1.5초)

깡패 변신(`GangTransformLogic`, 2초)과 **같은 구조**를 쓴다. 다른 점은 네 발 그대로라는 것뿐이다.

| 시간 | 일어나는 일 |
|---|---|
| 0.0 | 표를 밟는다 — 몸이 잠긴다(이동·공격 불가) |
| 0.0~0.4 | 총이 알파로 사라진다(총 넣기) |
| 0.3~0.5 | 상체를 든다 — 앞발이 뒷주머니로 |
| 0.5~1.1 | **칼이 알파로 나타난다**(꺼내는 순간 짧은 금속 소리) |
| 1.1~1.5 | 칼을 한 번 세우고 자세를 되돌린다 |

- **행동 중에 표를 밟으면** 그 행동은 성공시키고 변신한다(`ICompletableAction` — 깡패와 같은 규약).
- 늦게 들어온 사람·재접속에는 연출 없이 결과만 보인다(`GangLook.m_PhaseBound`와 같은 처리).

### 5-2. 무적 — 켜는 순간과 도는 동안

- 켤 때: 몸 주위로 **흰 빛이 한 번 퍼진다**(`FxId` 신규 1개, 기존 `Build Skill Effects` 생성기에 추가).
- 도는 동안: 몸 머티리얼에 **옅은 흰 테두리**(이미 있는 실루엣 머티리얼을 재사용 — 빛 전직이 쓰는 것).
- 끝날 때: 테두리가 0.3초에 걸쳐 꺼진다.
- **규칙 §11(이펙트는 한 번 터지고 끝난다)의 예외다** — 무적은 상대도 알아야 하는 상태라 지속 표시가 필요하다.

### 5-3. 애니메이션 (블렌더 자작)

| 클립 | 내용 | 원본 |
|---|---|---|
| `SwordSwing` | 앞발로 칼을 좌우로 한 번 벤다. 0.6초 | `tools/blender/clips/club_swing.py`를 본뜬 새 파일 |
| `HeroDraw` | 총을 넣고 칼을 뽑는 1.5초 — 상체를 살짝 든다 | 새 파일. 깡패 `gang_transform.py`의 앞부분 구조 재사용 |
| `Stunned` | 맞아서 굳은 자세(제자리에서 미세하게 떨림) | 새 파일. 짧고 루프 |

- 세 클립 다 `AnimationStateLogic.MouseOnly`에 넣고 **`Tools/CTC/Dev/Bake Mouse Gun`을 돌려야** AC_Mouse에 상태가 생긴다.
- 바닥 관통은 `measure_clip.py`로 1/4프레임 간격 측정 후 통과해야 한다.

### 5-4. 칼 소품

- `Tools/CTC/Dev/Bake Hero Props` 신규 메뉴 — `Bake Gang Props`와 같은 방식(코드로 메시를 굽고 손 뼈에 붙인다).
- 칼은 **반투명 머티리얼로 굽는다** — 알파로 나타나야 하므로(불투명이면 URP가 알파를 조용히 무시한다).
- 모양: 손잡이 + 곧은 날. 쥐 몸 길이의 60% — 크면 네 발 자세에서 바닥을 뚫는다.

## 6. 구조

| 조각 | 종류 | 책임 |
|---|---|---|
| `HeroSwordLogic` | 순수 static | 부채꼴 판정·피해·스턴 시간 (깡패 `GangLookLogic.InArc` 재사용) |
| `HeroSword` | Component | 서버에서 휘두르고 맞은 대상에 `Stun`을 건다 |
| `Stun` | Component (NetworkBehaviour) | `StunUntil` 복제값 하나. 입력 가드들이 이 값을 본다 |
| `StunLogic` | 순수 static | 「지금 막혀 있나」 · 겹침 갱신 규칙 |
| `HeroLook` | Component | 칼·변신 연출. `GangLook`과 같은 형태 |
| `HeroTransformLogic` | 순수 static | 1.5초 시간표 — 런타임과 GIF 미리보기가 같이 본다 |
| `MousePopgun` | 기존 수정 | 용사면 발사가 `ServerSword`로 간다(깡패 `ServerClub`과 같은 갈래) |

**공격 버튼은 하나다.** 좌클릭 → `MousePopgun.FireRpc` → 직업에 따라 총 / 몽둥이 / 칼로 갈린다.

## 8. 잘라낸 것

- **칼 테크(레벨업)**: 용사는 표 하나로 완성이다. 레벨을 붙이면 상점 카탈로그가 11번째를 갖는다.
- **막기·패링**: 새 입력과 새 클립이 또 필요하다. 무적 하나로 충분하다.
- **용사 두 발 서기**: 깡패의 정체성이다. 용사는 네 발 그대로 칼을 쓴다.
- **스턴 저항·면역**: 대상이 셋뿐이고 0.8초라 필요 없다. 연쇄 스턴이 문제가 되면 그때 본다.

## 9. 열린 질문

- 평소(걷는 동안)에도 용사임을 드러낼 표식이 필요한가 — 망토·머리띠 같은 소품. 지금은 변신·휘두르기·능력 바로만 드러난다(§10).
