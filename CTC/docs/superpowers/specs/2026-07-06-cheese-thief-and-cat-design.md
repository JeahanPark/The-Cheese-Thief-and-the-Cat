# 치즈 도둑과 고양이 (The Cheese Thief and the Cat) — 게임 디자인 스펙

**작성일:** 2026-07-06 · **1차 개정:** 2026-07-12 (원작 약올리기 DX 회귀) · **2차 개정(v2):** 2026-07-12 저녁 · **3차 개정(v3):** 2026-07-16 — 원작 충실 복귀 · **v3.1:** 2026-07-16 — §8 맵을 방-통로 구조 + 생성 툴로 개정 · **v3.2:** 2026-07-22 — 고양이 재화 '장난기(Fun)' 도입 (§6, **미구현**)
**상태:** v3.1 승인 — v2 구현 완료 위에 v3 개정분 반영 예정
**플랫폼:** PC 우선 · Unity URP (스토어 독립)
**엔진/기술:** Unity, Netcode for GameObjects (NGO), UGS Multiplayer Services (Relay + Lobby)

> **v3 개정 요지 (원작 약올리기 DX 재검증 결과):** 원작은 "시간제한 없는 소모전"이 **아니라** 초장기 안전 타이머(66:40, 도달 시 술래 강제패)가 있는 소모전이며, 회복 벙커가 시민의 거점이다. v2는 타이머를 핵심 페이싱(5분)으로 당기고 굶주림을 발명해 원작과 멀어졌다. v3는 원작 구조로 복귀:
> ① **타이머 = 안전장치** — 10:00 하드캡(도달 시 고양이 강제패 = 쥐 생존승). 핵심 압박은 타이머가 아니라 소모전 자체
> ② **치즈 = 순수 화폐** — 유지비/굶주림 삭제 (원작에 없음)
> ③ **초기 벙커 = 게임의 중심 거점** — 시작 시 **쥐 1마리당 자기 요새 1개** 무료 배치(각자 스폰 지점). 진입형: 쥐만 통과하는 입구(v2 쥐구멍 물리 재활용)로 내부 진입 → 안에서 회복. 고양이는 요새 외벽(HP)을 부숴야 내부 노출. 진입은 아무 쥐나 가능(초기 배치만 개인별). 상점 요새 = 영역 확장/재건축용 추가 건설
> ④ **쥐 전용 터널 삭제** — 원작에 시민 전용 지형 없음(안전은 벙커가 담당). v1 맵(가구 그레이박스)으로 복귀
>
> (v1 개정 이유: 초안의 변장 스텔스 축 제거, 원작 약올리기 DX 구조 채택 — 유지)

## 1. 한 줄 컨셉

3D 3인칭 비대칭 멀티 소모전 — **쥐들은 고양이 코앞에서 치즈를 벌어 무장하고 요새를 지으며 고양이를 서서히 말려 죽인다. 고양이는 쥐가 다 벌기 전에 전멸시켜야 한다.**

## 2. 레퍼런스

| 소스 | 가져오는 것 |
|------|-----------|
| **약올리기 DX** (스타크래프트 UMS) | **게임 규칙 전체** — 등급제 돈줄(위험=고수입), 시민이 술래를 죽이는 승리 구조, 사망=탈락·관전, 벙커(회복 거점), 양측 상점 경제, 소모전 + 초장기 안전 타이머(타임오버 시 술래 강제패) |
| **MECCHA CHAMELEON** | 3D 3인칭 시점·자유 카메라·관전 **연출만** (변장/스텔스 시스템은 채택 안 함) |

## 3. 핵심 재미 (Core Hook)

> **"고양이 코앞의 금싸라기 치즈에서 벌고 빠져라(약올리기) — 번 돈으로 무장해 고양이를 말려 죽여라(소모전)."**

- 수입과 리스크가 **같은 장소** — 좋은 치즈 지점일수록 고양이 동선 한복판.
- 단일 자원 풀 — 무기를 살까, 도주템을 살까, 요새를 지을까.
- 고양이도 경제 주체 — 쥐를 잡아 벌고, 상점으로 강해짐. 양측 모두 "말려 죽이기" 게임.

| 항목 | 값 |

| 시간 | **10:00 안전 타이머** (v3) — 교착 방지용 하드캡, 도달 시 고양이 강제패. 원작 66:40의 축소 대응 |

| 커뮤니케이션 | 근접 보이스챗 (거리 기반, 뮤트 키) — 약올리기 수단 |

### 승패 (v3 — 원작 동일 구조)

| 판정 | 조건 |
|------|------|
| **쥐 팀 승** | ① **고양이 전원 처치** (주 승리 경로) or ② **타임캡(10:00)까지 1마리라도 생존** (교착 방지 안전장치) |

## 5. 코어 루프

```
게임 시작 — 쥐마다 자기 요새(진입형 거점)에서 출발 · 등급별 치즈 지점 활성 (안전 타이머 10:00 백그라운드)
  ├─ 쥐: 요새 대기 ↔ 치즈 지점에서 벌기 왕복 (위험 지점일수록 고수입)
  │     ├─ 위험하면 요새 안으로 — 내부 회복, 고양이는 외벽을 부숴야 함
  │     ├─ 상점: 무기(고양이 공격)·도주/교란템·추가 요새 — 단일 지갑
  │     └─ 무기로 고양이 HP를 갉아 서서히 말려 죽임 (주 승리 경로)
  └─ 고양이: 순찰 → 쥐 처치 = 보상 / 요새 공성(부수면 거점 상실) — 압박 수단
        └─ 고양이도 치즈 지점 수입 가능 + 전용 상점으로 강화 — 돈줄 봉쇄 플레이
종료: 고양이 전멸(쥐 승) / 쥐 전멸(고양이 승) / 타임캡(쥐 생존승)
```

## 6. 역할 상세

### 쥐 (6마리까지 · 개인 지갑 · 공동 목표)

| 요소 | 내용 |
|------|------|
| 수입 | 치즈 지점 **점유 수입** — 지점 안에 있는 동안 초당 획득. **한 지점당 1마리만** 수입(원작 "중복 수입 없음" → 쥐끼리 자리 경쟁) |
| 생존 | 기본 저HP. **회복 = 요새 내부**(진입형 거점 — 원작 벙커). HP 0 = **탈락·관전** |
| 거점 | **초기 요새 1개**(각자 스폰 지점, 무료) — 쥐 전용 입구로 진입, 내부 회복. 고양이가 외벽을 부수면 상실. 진입은 아무 쥐나 가능 |
| 공격 | 상점 무기로 고양이 원거리 견제 (티어: 딱총 → 새총 → 기관총급, 원작 80/150/600원 구도) |
| 밀당 | 도주(대시)·교란(미끼·유인) 아이템 + 근접 보이스로 약올리기. **추가 요새 구매**(영역 확장·재건축) |

### 고양이 (1~2마리 · 보스형)

| 요소 | 내용 |
|------|------|
| 스탯 | **고HP 보스** (원작 질럿 체력 1000+실드 500 + 공격력 성장 구도) |
| 공격 | 덮치기(근접, 쿨다운). **요새 공성** — 외벽 HP를 부숴 쥐 거점 박탈 |
| 수입 | **장난기(Fun)** — 고양이 유일 재화, 치즈 개념 없음 (v3.2 개정, **미구현**). 적립(서버 권위, 실데미지 기준): ① 쥐에게 준 데미지 1 = 1pt (남은 HP만큼만 — 과잉타격 미적립) ② 쥐 구조물(요새·미끼) 데미지 동일 1:1 ③ 킬 보너스 +20pt. **의도: 즉살(120pt)보다 살려두고 갖고 노는 쪽이 수입 우위** — 요새 회복(+10/s)과 맞물려 반복 타격이 저속 무제한 수입원(착취 아닌 의도된 플레이). 상점 결제 수단만 장난기로 교체(가격 동일). HUD는 고양이에게 `Fun: N` 표시(쥐는 `Cheese:` 유지). 구현 시 CheeseWallet 범용 재사용 + Health.TakeDamage 실데미지 반환 |
| 상점 | 전용 상점 — 이동·감지·공격 강화, 견제 수단(원작 꼬맹이·닭 = 하수인 소환 대응) |
| 협업 | 2마리일 때 협공 |

## 7. 경제 & 상점

### 치즈 지점 (원작 돈줄)

- **등급 1~7** — 등급 높을수록 초당 수입 큼, 위치는 고양이 동선·개활지 등 위험 지역 (원작 1~7원 돈줄)
- 지점당 **동시 수입 1마리** — 선점 경쟁
- 지점은 소멸하지 않음(상시) — 리스폰 개념 없음, 위치 밸런스로 통제
- 치즈는 **순수 화폐** (v3) — 자동 소모·유지비 없음 (원작에 없는 시스템)

### 상점 (양측, 자원 차감)

| 쥐 | 고양이 |
|----|--------|
| 무기 3티어 (딱총/새총/기관총급) | 공격력·이속 강화 |
| 도주: 대시 · 교란: 미끼/유인 | 감지 강화(발소리 레이더급) |
| **추가 요새** (진입형 회복 거점 — 초기 요새와 동일 사양) | 하수인/견제 수단 |

MVP는 분류당 1~2개만 (스코프 §10).

## 8. 맵 (v3.1 — 방-통로 구조)

> **v3.1 개정 (2026-07-16):** 사용자 맵 시안 채택 — "개활지 + 가구 장애물"을 폐기하고 **방-통로 그래프** 구조로 전환. 맵은 에디터 생성 툴로 제작 (상세: [맵 생성 스펙](2026-07-16-map-generation-design.md))

| 항목 | MVP (v3.1) |
|------|-----|
| 구조 | **방(큰 지형) + 통로(좁은 연결로) + 미로 구간**, 바깥은 이동 불가 — 던전식. 그레이박스, 아트는 8-B |
| 통로 | **양측 통과 가능** (쥐 전용 지형 없음 — v3 원칙 유지). 좁은 길목 = 회피 불가 리스크 |
| 맵 수 | 생성 툴 기반 라이브러리 (후보지 풀 + 시드 랜덤 + 손시안). 매치당 1개 선택해 씬에 굽기 |
| 안전 지대 | **지형으로는 없음**. 안전은 **요새**(초기 배치 + 구매) + 방·미로의 시야 차단으로 |
| 초기 요새 | 쥐 스폰 = 각자 요새 위치. **외곽 방들에 분산** (한 곳이 뚫려도 다른 요새로 피난) |
| 치즈 지점 | 등급 = 위험도 — 저등급 외곽 방·요새 인접, 고등급 중심 방(연결 많고 통로 노출 큰 곳) |
| 리듬 | 요새 대기 → 치즈존에서 벌기 → 고양이 접근 시 통로 타고 가장 가까운 요새로 → 다시 벌러 |
| v3에서 변경 | v1 가구 그레이박스 → 방-통로 구조 + 맵 생성 툴 (하드코딩 맵 폐기) |
