# 치즈 도둑과 고양이 (The Cheese Thief and the Cat) — 게임 디자인 스펙

**작성일:** 2026-07-06 · **1차 개정:** 2026-07-12 (원작 약올리기 DX 회귀) · **2차 개정(v2):** 2026-07-12 저녁 — 사용자 결정
**상태:** v2 승인 — v1 코어 구현 완료 위에 v2 개정분 반영 예정 ([로드맵](../plans/2026-07-06-mvp-roadmap.md))
**플랫폼:** PC 우선 · Unity URP (스토어 독립)
**엔진/기술:** Unity, Netcode for GameObjects (NGO), UGS Multiplayer Services (Relay + Lobby)

> **v2 개정 요지:** ① **5분 타이머** — 쥐는 생존해도 승리(승리 2경로), 고양이는 시간 내 전멸시켜야 함 ② **치즈 = 식량+화폐** — 일정 주기 자동 소모(유지비), 부족하면 HP를 대신 소모(굶주림) ③ **쥐 전용 터널**(물리 크기 지형) — 안전 지대는 레벨디자인으로 ④ 요새 삭제 · 회복 없음. 존버 방지 논리가 "숨으면 승리 불가"(v1)에서 **"숨으면 굶는다"**(v2)로 교체됨.
>
> (v1 개정 이유: 초안의 변장 스텔스 축 제거, 원작 약올리기 DX 구조 채택 — 유지)

## 1. 한 줄 컨셉

3D 3인칭 비대칭 멀티 생존 경제전 — **쥐들은 치즈로 연명하며 5분을 버틴다. 고양이를 잡아도 이기고 살아남아도 이긴다. 고양이는 시간 안에 쥐를 전멸시켜야 한다.**

## 2. 레퍼런스

| 소스 | 가져오는 것 |
|------|-----------|
| **약올리기 DX** (스타크래프트 UMS) | **게임 규칙 전체** — 등급제 돈줄(위험=고수입), 시민이 술래를 죽이는 승리 구조, 사망=탈락·관전, 벙커(회복 거점), 양측 상점 경제, 시간제한 없는 소모전 |
| **MECCHA CHAMELEON** | 3D 3인칭 시점·자유 카메라·관전 **연출만** (변장/스텔스 시스템은 채택 안 함) |

## 3. 핵심 재미 (Core Hook)

> **"고양이 코앞의 금싸라기 치즈에서 벌고 빠져라(약올리기) — 번 돈으로 무장해 고양이를 말려 죽여라(소모전)."**

- 수입과 리스크가 **같은 장소** — 좋은 치즈 지점일수록 고양이 동선 한복판.
- 단일 자원 풀 — 무기를 살까, 도주템을 살까, 요새를 지을까.
- 고양이도 경제 주체 — 쥐를 잡아 벌고, 상점으로 강해짐. 양측 모두 "말려 죽이기" 게임.

## 4. 플레이 구조

| 항목 | 값 |
|------|-----|
| 인원 | 고양이 1~2 vs 쥐 3~6 (로비 가변) — 원작 시민 6 : 술래 2 |
| 팀 구조 | 쥐는 개인 경제(각자 지갑)지만 **고양이 처치는 공동 목표** |
| 시간 | **5분 타이머** (v2) — 종료 시 생존 쥐가 있으면 쥐 승 |
| 시점 | 3D 3인칭 + 자유 카메라(몸 안 움직이고 훔쳐보기) |
| 커뮤니케이션 | 근접 보이스챗 (거리 기반, 뮤트 키) — 약올리기 수단 |

### 승패 (v2)

| 판정 | 조건 |
|------|------|
| **쥐 팀 승** | ① **고양이 전원 처치** or ② **시간 종료까지 1마리라도 생존** |
| **고양이 승** | **시간 내 쥐 전원 사망** (죽은 쥐는 탈락 → 관전, 부활 없음) |

시간 압박은 고양이 쪽 — 고양이가 사냥에 적극적이어야 하는 구조.

## 5. 코어 루프

```
게임 시작 — 5분 타이머 · 맵에 등급별 치즈 지점 활성
  ├─ 쥐: 터널 대기 ↔ 치즈 지점에서 벌기/먹기 왕복 (위험 지점일수록 고수입)
  │     ├─ 치즈는 일정 주기 자동 소모(유지비) — 부족하면 HP 대신 소모(굶주림)
  │     ├─ 상점: 무기(고양이 공격)·도주/교란템 구매 — 식량과 같은 지갑
  │     └─ 무기로 고양이 HP를 갉거나, 생존에 올인하거나 (승리 2경로)
  └─ 고양이: 순찰 → 쥐 공격(덮치기)으로 처치 = 보상 획득 — 시간에 쫓기는 쪽
        └─ 고양이도 치즈 지점 수입 가능 + 전용 상점으로 강화
종료: 고양이 전멸(쥐 승) 또는 쥐 전멸(고양이 승)
```

## 6. 역할 상세

### 쥐 (6마리까지 · 개인 지갑 · 공동 목표)

| 요소 | 내용 |
|------|------|
| 수입 | 치즈 지점 **점유 수입** — 지점 안에 있는 동안 초당 획득. **한 지점당 1마리만** 수입(원작 "중복 수입 없음" → 쥐끼리 자리 경쟁) |
| **유지비 (v2)** | 치즈를 일정 주기 자동 소모. **치즈 부족 시 HP를 대신 소모(굶주림)** — 숨어만 있으면 굶어 죽음 |
| 생존 | 기본 저HP, **회복 없음(v2)** — 전투·굶주림 피해 전부 누적. HP 0 = **탈락·관전** |
| 안전 지대 (v2) | **쥐 전용 터널**(맵 지형 — 물리 크기로 고양이 진입 불가). 안에선 수입 0 → 유지비만 진행 |
| 공격 | 상점 무기로 고양이 원거리 견제 (티어: 딱총 → 새총 → 기관총급, 원작 80/150/600원 구도) |
| 밀당 | 도주(대시)·교란(미끼·유인) 아이템 + 근접 보이스로 약올리기. ~~쥐 요새~~(v2 삭제) |

### 고양이 (1~2마리 · 보스형)

| 요소 | 내용 |
|------|------|
| 스탯 | **고HP 보스** (원작 질럿 체력 1000+실드 500 + 공격력 성장 구도) |
| 공격 | 덮치기(근접, 쿨다운) — 쥐 처치 시 **보상 치즈** |
| 수입 | 처치 보상 + **고양이도 치즈 지점 점유 수입 가능** (원작 동일 — 돈줄 봉쇄 플레이) |
| 상점 | 전용 상점 — 이동·감지·공격 강화, 견제 수단(원작 꼬맹이·닭 = 하수인 소환 대응) |
| 협업 | 2마리일 때 협공 |

## 7. 경제 & 상점

### 치즈 지점 (원작 돈줄)

- **등급 1~7** — 등급 높을수록 초당 수입 큼, 위치는 고양이 동선·개활지 등 위험 지역 (원작 1~7원 돈줄)
- 지점당 **동시 수입 1마리** — 선점 경쟁
- 지점은 소멸하지 않음(상시) — 리스폰 개념 없음, 위치 밸런스로 통제

### 치즈 유지비 (v2 — 식량 = 화폐)

- 쥐는 치즈를 **일정 주기 자동 소모** (생존 유지비). 상점 구매와 같은 지갑 — "무기냐 식량이냐"
- 소모 틱에 치즈 부족 → **HP를 대신 소모** (굶주림)
- 시작 시 소량의 치즈 지급 (초반 버퍼)
- 고양이는 유지비 없음

### 상점 (양측, 자원 차감)

| 쥐 | 고양이 |
|----|--------|
| 무기 3티어 (딱총/새총/기관총급) | 공격력·이속 강화 |
| 도주: 대시 · 교란: 미끼/유인 | 감지 강화(발소리 레이더급) |
| ~~쥐 요새~~ (v2 삭제 — 안전은 터널로) | 하수인/견제 수단 |

MVP는 분류당 1~2개만 (스코프 §10).

| 리듬 | 터널 대기 → 치즈존에서 벌기/먹기 → 유지비가 등을 떠밈 → 고양이 접근 시 가장 가까운 구멍으로 — [시안](../design-vault/맵%20시안%20v1.svg) |
