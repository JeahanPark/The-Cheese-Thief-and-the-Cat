# 치즈 도둑과 고양이 (The Cheese Thief and the Cat) — 게임 디자인 스펙

**작성일:** 2026-07-06
**상태:** 승인됨 (브레인스토밍 완료)
**플랫폼:** PC 우선 · Unity URP (스토어 독립)
**엔진/기술:** Unity, Netcode for GameObjects (NGO), UGS Multiplayer Services (Relay + Lobby)

---

## 1. 한 줄 컨셉

3D 3인칭 비대칭 멀티플레이 숨바꼭질 — **쥐(치즈 도둑)들이 각자도생으로 몰래 치즈를 먹어 아이템을 사며, 술래인 고양이를 약올리고 피해 제한시간까지 살아남는다.**

## 2. 레퍼런스

| 소스 | 가져오는 것 |
|------|-----------|
| **약올리기 DX** (스타크래프트 UMS) | 돈줄(치즈) 경제, 상점/아이템, 술래를 "약올리는" 밀당, 술래도 성장 |
| **MECCHA CHAMELEON** | 3D 3인칭 시점, 변장/위장 스텔스, 자유 카메라, 관전, 숨는 쪽 vs 찾는 쪽 구도 |

## 3. 핵심 재미 (Core Hook)

> **"몰래 숨어서 훔쳐 먹되(스텔스), 아슬아슬하게 약올리며 벌고(밀당), 안 잡히고 살아남아라(생존)."**

밀당의 핵심 긴장:
- 치즈를 **그 자리에서 먹는 동안 무방비·노출** → 벌려면 위험을 감수해야 함.
- 자원(먹은 치즈)은 **단일 풀** — 아이템을 사면 그만큼 줄어듦. **살려고 쓸까 vs 아껴서 여유를 둘까.**
- 아이템을 쓰면 그 순간은 살지만, 자원이 줄어 다시 위험하게 벌어야 함(재노출 루프).

---

## 4. 플레이 구조

| 항목 | 값 |
|------|-----|
| 인원 | 고양이 1~2 vs 쥐 3~6 (로비 인원에 따라 **가변**) |
| 팀 구조 | 쥐는 **개인전(각자도생)** — 쥐끼리도 경쟁, 고양이는 공통의 위협 |
| 한 판 | 라운드제, 제한시간 5분 내외 |
| 시점 | 3D 3인칭 + 자유 카메라(몸 안 움직이고 주변 훔쳐보기) |

### 승패 조건 (순수 생존)

| 역할 | 승리 조건 |
|------|-----------|
| **쥐** | 제한시간 종료까지 **안 잡히고 생존**하면 승. 잡히면 **탈락**(그 판 패). |
| **고양이** | 제한시간 내 **쥐 전원 색출/포획**. 한 명이라도 살아남으면 그 쥐만 승. |

- 치즈에는 **목표량 없음** — 순수하게 아이템 구매용 자원.
- 잡힌 쥐 = **관전**(MECCHA식 자유 카메라로 남은 판 구경).

## 5. 코어 루프

```
라운드 시작
  └─ 맵 곳곳에 치즈 지점 스폰
       ├─ 쥐: 치즈 지점에서 그 자리 먹기 (= 개인 자원 획득, 먹는 동안 무방비·노출)
       │       └─ 자원으로 상점 아이템 구매 (자원 차감)
       │       └─ 변장·시야·발소리 관리하며 안전 동선 확보
       └─ 고양이: 순찰 + 후각으로 추적 → 먹는 중인 쥐 덮치기
                   └─ 포획 성공 → 해당 쥐 탈락(관전 전환)
라운드 종료 (시간 소진)
  ├─ 살아남은 쥐 → 각자 승리
  └─ 쥐 전원 포획됨 → 고양이 승리
```

## 6. 역할 상세

### 쥐 (치즈 도둑 / 숨는 쪽)

| 요소 | 내용 |
|------|------|
| 시점 | 3인칭 + 자유 카메라로 고양이 위치 훔쳐보기 |
| 핵심 능력 | **변장**(소품 위장·배경색으로 고양이 눈 속임) + **시야/발소리 관리** |
| 자원 획득 | 치즈 지점에서 그 자리 먹기(먹는 동안 이동 불가·노출) |
| 밀당 수단 | 아이템으로 고양이 유인·교란·약올리기 |

### 고양이 (술래 / 헌터)

| 요소 | 내용 |
|------|------|
| 시점 | 3인칭, 근접감 위해 시야 넓게 |
| 핵심 능력 | 넓은 시야 · **덮치기**(쿨다운) · **후각**(근처 쥐·치즈 감지) |
| 성장 | 쥐 포획 + 시간당 소량으로 포인트 획득 → 능력 강화 |
| 협업 | 2명일 때 시야 공유·협공 |

## 7. 경제 & 아이템

### 자원 규칙 (단일 풀)

- 먹은 치즈 = 개인 자원 풀.
- 아이템 구매 시 자원 차감(별도 점수/승리 게이지 없음 — 순수 구매 통화).

### 쥐 아이템 (분류)

| 분류 | 예시 | 역할 |
|------|------|------|
| **도주** | 대시, 순간 은신(짧은 투명), 벽타기 | 덮치기 직전 탈출 |
| **교란** | 가짜 쥐(미끼 클론), 냄새폭탄(후각 차단), 소음 유인 | 고양이 오판 유도·약올리기 |
| **함정** | 미끄럼·끈끈이(고양이 잠깐 묶기) | 길목 방어 |
| **정보** | 고양이 위치 핑, 발소리 레이더 | 안전 동선 확보 |
| **변장** | 위장 완성도↑ · 유지시간↑ | 그 자리 먹기 안전화 |

### 고양이 능력 성장

| 기본 | 성장(포인트로) |
|------|--------------|
| 넓은 시야 · 덮치기(쿨다운) · 후각 | 질주 대시 · 후각 강화 · 함정 감지 · 변장 간파 |

---

## 8. 스텔스 시스템 (변장 + 시야)

- **변장:** 소품으로 변신하거나 배경색에 맞춰 위장 → 고양이가 근접하거나 특정 조건(움직임·소리·후각)에서 간파.
- **시야/소리:** 고양이는 시야각 + 발소리 + 후각으로 쥐를 인지. 쥐는 이 세 축을 관리해 노출 최소화.
- 치즈를 먹는 중엔 변장 효과 약화/해제 → 먹기 = 노출 리스크.

## 10. 기술 아키텍처

| 레이어 | 선택 |
|--------|------|
| 네트워크 | **Netcode for GameObjects**, **호스트(리슨 서버) 권위** — 이동·포획·자원 판정을 서버가 결정(치팅 방지) |
| 매치메이킹 (개발/테스트) | **UGS Multiplayer Services (Relay + Lobby)** — 스토어 독립, 무료 티어(동시 50인)로 인터넷 테스트. 참가코드로 방 참가 |
| 매치메이킹 (출시) | **Steam 로비 + SteamNetworkingSockets 트랜스포트**로 교체 예정 |
| 트랜스포트 추상화 | 연결 층을 인터페이스로 감싸 **UGS Relay ↔ Steam ↔ Direct IP** 를 최소 코드 변경으로 교체 가능하게 설계 |
| 동기화 | 위치 = NetworkTransform(보간) · 자원/상점/변장 상태 = NetworkVariable / RPC |
| 범위 밖(MVP) | 데디케이티드 서버, 호스트 마이그레이션, 랭크 시스템 |

## 12. 아트 / 플랫폼

- **3D 스타일라이즈드** (귀엽고 코믹한 쥐 vs 고양이)
- 3인칭 시점
- **PC 우선, 출시 스토어는 Steam 지향** — 단 개발/테스트는 스토어 독립(UGS)이라 Steam 클라이언트 없이도 붙는다. 모바일 렌더러는 보류(프로젝트에 존재하나 MVP 대상 아님)
