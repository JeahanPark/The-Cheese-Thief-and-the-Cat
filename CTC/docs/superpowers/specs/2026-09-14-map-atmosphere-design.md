# 맵 분위기 패스 — 밤 하늘 · 전등 · 빛줄기 · 먼지 · 후보정 (2026-09-14)

> 사용자 요청: "맵아트에 이펙트, 쉐이더 효과, 전등 등 한번 더 디자인을 예쁘게". 방식은 추천안으로 진행(사용자 부재 중 지시).
> 기존 기획: [2026-08-31 밤 팬트리](2026-08-31-night-pantry-map-art-design.md) — "빛 = 위험", 딤 블루 달빛 + 앰버 빛웅덩이.
> **이번 패스는 그 톤을 유지한 채 "보이게" 만든다.** 밸런스·시야·충돌은 하나도 안 바꾼다.

## 지금 문제 (창고 맵 실측 스크린샷, 2026-09-14)

| # | 문제 | 원인 |
|---|---|---|
| 1 | 벽 위로 **낮 하늘**이 보인다 | `Game.unity`가 기본 스카이박스 그대로 |
| 2 | 빛웅덩이가 **어디 있는지 안 보인다** — 광원 자체가 없다 | 점광원만 있고 전등 물체·빛줄기가 없다 |
| 3 | 화면이 **회색 진흙** — 대비·색이 없다 | 후보정 Volume이 없다(블룸 0 · 톤매핑 없음) |
| 4 | 공기가 **비어 있다** | 입자·빛줄기가 없다 |

## 무엇을 넣나

| 층 | 내용 | 비용 |
|---|---|---|
| 하늘 | 밤 스카이박스(짙은 남색 그라데이션, 태양 원반 0) | 0 |
| 전등 | 앰버 빛웅덩이마다 **매달린 전등**(줄·갓·HDR 전구) + **빛줄기 원뿔**(`CTC/LightCone`, 가산) + 전구 주위 **먼지 입자** | 전등당 드로우콜 4 + 입자 ≤ 24 |
| 달빛 | 달빛 자리에 **푸른 빛기둥**(넓고 옅은 원뿔) + 먼지 | 동일 |
| 흔들림 | 전등의 약 1/3이 **아주 약하게 깜빡**(빛 세기 ±12%) — 시드·위치 해시로 전원이 같은 전등 | Update 몇 개 |
| 후보정 | 전역 Volume — ACES 톤매핑 · 블룸(전구·빛줄기만 번지게 임계 1.0) · 스플릿 톤(그림자 남색/하이라이트 앰버) · 대비 · 비네트 | 풀스크린 1~2패스 |

**어둠 기능(`DarknessFeature`)은 그대로다** — 그 패스는 투명 뒤·후보정 앞이라, 후보정은 어두워진 화면을 받아 색만 입힌다.

## 안 바꾸는 것

빛의 **개수·자리·반경**(스텔스 판정과 봇 동선이 그 위에 서 있다) · 콜라이더 · BotLab의 낮 조명(관찰용).

## 구조

- `MapAtmosphereProfile`(ScriptableObject, `Resources/Map/MapAtmosphere`) — 전등·달빛 프리팹, 밤 하늘, 후보정 프로필을 든다.
  **Resources인 이유**: 씬(`Game.unity`)을 다시 굽지 않고 붙는다 — `Setup Networking Scene` 재생성은 해시·클론 재시작 비용이 크다.
- `MapAtmosphere`(static) — `MapDresser`가 빛웅덩이를 놓을 때 전등을 붙이고, 첫 적용 때 하늘·Volume·카메라 후보정을 켠다.
  **밤 판정은 `RenderSettings.fog`** — BotLab은 안개를 끈 낮 조명이라 자동으로 빠진다.
- `LampFlicker` — 전등 하나의 깜빡임(빛 + 전구 발광 MPB).
- 에디터 `MapAtmosphereBuilder` — 메시(갓·줄·원뿔)·머티리얼·프리팹·프로필을 코드로 굽는다(메뉴 `Tools/CTC/Map/Build Atmosphere`). 있으면 덮어써도 되는 생성물이다(손으로 고칠 것이 없다).
