## 현재 위치

- 후추 선반 ①(후추 탄) ✅ — 도트 4초·초당 3·3중첩, 전부 CSV
- **핫바 6칸이 정확히 찼다** — 다음 항목부터는 기획안의 「확정 후 카탈로그 교체」 UI가 전제다

## Phase 0 — 남은 클라이언트 검토 3건 (착수 게이트)

| # | 검토 | 확인 방법 |
|---|---|---|

| ③ | 트리거 볼륨 3종(꿀 장판·덫·밀가루 구름) | 요새 즉시배치(`SpawnFortressAround`) + `FortressShield` 트리거 패턴 재사용 검증 |

## Phase 1 — 노선 시스템 뼈대 (배타성의 기반)

- `ShopInfo.csv`에 `Branch.BranchId`·`ChoiceGroup.int` 컬럼 추가(기획안 방식 — 새 표 없음)
- `MouseBranch` 컴포넌트(쥐 프리팹): 노선 확정 NetworkVariable — 노선 첫 구매 시 확정
- `ShopLogic.RoleCatalogIndices` → 노선 인식 버전(확정 전 공용+①들 / 확정 후 내 노선만)
- 핫바 UI: 노선 확정 순간 카탈로그 교체 + 확정 토스트
- EditMode: 카탈로그 전환 순수 로직 테스트
- **이 시점에서 후추 탄을 후추 노선 ①로 이관** (지금은 공용 6번 슬롯)

## Phase 2 — 후추 선반 완성

- ③ 굵은 소금 산탄: `WeaponInfo` Tier 3 행 + 부채꼴 3발(`PelletCount`·`SpreadHalfAngleDeg`) + ②/③ 택1
- 신규 리소스: 산탄 발사 이펙트·사운드 (연출 패스 S1~S2 표준 경유)

## Phase 3 — 꿀 선반 (장판·덫·벌집)

- 꿀단지 장판(고양이만 감속) → 끈끈이 덫(1.2초 속박) / 벌집 요새(HP 720) 택1
- 트리거 볼륨 공통 베이스 `GroundZone` 하나 만들어 셋이 공유

## Phase 4 — 밀가루 선반 (은폐·경제)

- 밀가루 구름(시야 차단) · 창고 전용화(기획안 P8 — 노선 내 상한 조정 포함)

## Phase 5 — 고양이 3부위 (코·수염·발톱)

- **전직 조건 1050 → 진입권 300** (기획안 P4) — `ShopLogicTests.Balance_CatAdvancementIsReachableWithinOneMatch` 재작성(5~10킬 → 2~4킬)

- 개막 카드(0:00, 60치즈) 3종
