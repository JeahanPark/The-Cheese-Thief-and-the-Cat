## Unity 프로젝트에서의 테스트 전략

- **순수 C# 로직**(입력 변환, 자원 계산, 감지 판정, 승패 상태기계) → Unity Test Framework **EditMode 테스트**로 TDD. MonoBehaviour에서 로직을 분리해 테스트 가능하게 설계한다.
- **네트워크/비주얼 동작** → **Multiplayer Play Mode(MPPM)** 가상 플레이어로 수동 PlayMode 검증. 기대 관찰값을 명시한다.
- MCP-Unity 서버가 연결돼 있으면 콘솔 확인·플레이 토글·스크린샷을 자동화할 수 있으나, 계획의 검증 단계는 수동 기준으로 기술한다.
