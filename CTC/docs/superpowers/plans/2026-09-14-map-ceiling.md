# 맵 천장 꾸미기 — 작업 계획

요청(2026-09-14): "지금 보면 맵이 천장이 비어 있는데 거기도 꾸며줘".
상태: ☐ 할 일 · ◐ 진행 중 · ☑ 완료(검증까지) · ✕ 보류(사유)

## 현재

- 방 벽 5m · 복도 벽 2.4m 위가 **그냥 밤 하늘**이다. 카메라를 올려다보면(최소 피치 -16°) 벽 너머로 하늘이 뚫려 보인다.
- 카메라는 거리 3m · 최대 피치 75° → 높이 ≈ 4m를 넘지 않는다 — **6m 천장은 시야를 가리지 않는다.**

## 설계

| 층 | 높이 | 내용 |
|---|---|---|
| 천장 판 | 6.0m | 4m 칸 나무 판(`T_WoodCrate` 트리플래너) — **빈틈 없이 전부 덮는다** |
| 큰 들보 | 5.45~6.0m | X 방향, 8m 간격 |
| 장선 | 5.78~6.0m | Z 방향, 1.6m 간격 |
| 닫힌 채광창 | 5.76~6.0m | 달빛 자리 칸: 판 밑 푸른 Unlit 유리 + 테 + 십자 창살 — 달빛 기둥의 출처 |
| 매달린 것 | 들보 아래 0.6~1.4m | 마늘 줄·양파 줄·소시지 줄·햄·밧줄 뭉치 — 들보 3m마다 1/5 확률. 전등·채광창 1.5m 안은 비운다 |

- **전부 비주얼 전용**: 콜라이더 없음 · 그림자 안 드리움(달빛 방향광이 판에 막히면 맵이 꺼멓게 된다) · 네비·스텔스 판정 무관.
- 밤일 때만(`MapAtmosphere.IsNight`) — BotLab은 빠진다.
- 메시는 판·들보를 **한 메시로 합쳐** 드로우콜을 줄인다.
- 자리 계산은 순수 함수(`MapCeilingLogic`) → EditMode 테스트. 시드·위치 기반이라 전원이 같은 그림.

## 진행 기록
- 2026-09-14 계획 작성.
- 2026-09-14 구현·검증.
  - 첫 촬영에서 천장이 **새까만 구멍**이었다 — 밤 환경광(SH)은 아래를 향한 면에 거의 0이다. `CTC/MapTriplanar`에 `_FillLight`(기본 0 — 바닥·벽은 그대로)를 더하고 천장만 따뜻한 채움광을 준다.
  - 경계벽 위와 판 사이 틈으로 **밤 하늘이 띠처럼** 샜다 → 맵 둘레 판벽(3.5m~판).
  - 매달린 식료품이 푸른 밤빛에 **보랏빛 덩어리**로 보였다 → 제 색의 16%를 스스로 낸다(에미션).
  - 사용자: **뚫린 것보다 덮는 게 중요** → 채광창 칸도 판으로 덮고, 판 밑에 닫힌 유리창(Unlit 푸른빛 + 창살)을 단다. 게임 카메라로는 창을 못 잡아 **자유 시점 촬영 훅 `TestCaptureFreeView`**를 더해 찍었다 — 유리색 0.30·0.42·0.62는 후보정 뒤 흰 하늘처럼 떠 **구멍으로** 읽혀 0.10·0.15·0.24로 낮췄다(`images/map-ceiling-closed.png`).
  - 사용자: 컨셉 좋음 · **조금 밝히자** → 천장 채움광 약 1.9배(판 0.42·0.36·0.31 · 들보 0.56·0.47·0.39). 전등 웅덩이는 여전히 따로 읽힌다(`images/map-ceiling-bright-*.png`).
