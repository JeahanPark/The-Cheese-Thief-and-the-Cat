# 연출 패스 계획 — 기능 × 이펙트 × 사운드 × 애니 (2026-08-31)

> 근거: 사용자 지시("기획에 있는 기능들 이펙트·사운드가 없고 애니메이션도 별로") +
> 전수 조사 인벤토리(2026-08-31, 탐색 에이전트 — SFX 29곳 / 인게임 VFX 프리팹 0개 / 애니 5상태만 사용).

## 조사 요약 (계획의 전제)

- **사운드는 의외로 촘촘하다**(29곳) — 구멍은 소수: 덮치기 명중·잠행·탄착·점유·채팅 수신 + 임시 재사용 5건.
- **VFX가 통째로 없다** — 인게임 파티클은 창고 생산 1개뿐. 트레이서·피격은 코드 생성 임시물.
- **애니는 자산이 놀고 있다** — Quirky 컨트롤러에 `Death·Eat·Fear·Jump·Sit` 등 40여 상태가
  이미 있는데 5개(`Idle_A/Walk/Run/Attack/Hit`)만 쓴다. **새로 만들 필요 없이 붙이면 된다.**
- 고아 파일: `sfx_pounce_hit.ogg`가 **있는데 SfxId가 없어 미배선** — 게임 핵심 순간(덮치기 명중)이 무음.

## 표준 결정 (착수 전 1회)

| # | 결정 | 내용 |
|---|---|---|
| S1 | **FX 제작 경로 표준 = FX 프리팹** (`Prefabs/Fx/` + 팩토리 배선) | 지금은 코드 생성(창고)과 프리팹(인트로)이 혼재. 프리팹으로 통일 — designer 에이전트가 만들고 코드가 참조만 |
| S2 | FX 재생 진입점 = `FxPlayer.PlayAt(FxId, pos)` 정적 헬퍼 (SfxPlayer 대칭) | 호출부가 프리팹 경로를 모르게. 풀링은 기존 `PoolManager` 재사용 |
| S3 | 애니는 기존 Quirky 상태 재사용 우선, 신규 클립 제작은 최후 | `PlayerAnimationDriver.PlayOneShot` 확장으로 충분 |
