## 규칙 확인

- 수치는 CSV(`BalanceInfo`) — 코드에 박지 않는다.
- 색은 `UiPalette` 단독 출처 — 새 색 금지.
- Unity 객체는 `!= null`. `?.`·`??` 금지.
- View는 상태를 조회·판정하지 않는다 — 판정은 전부 `MinimapLogic`.
- **에디터는 하나다.** 플레이모드를 쓰는 태스크는 절대 병렬로 돌리지 않는다(계획 2b 실측).

## Task 1 — `MinimapLogic` (순수) + EditMode

`Assets/Scripts/UI/MinimapLogic.cs` · 테스트 `Assets/Tests/EditMode/MinimapLogicTests.cs`

- `Vector2Int WorldToPixel(Vector2 world, float halfExtent, int px)` — 월드 원점이 중앙, z+가 위.
- `RectInt RectToPixels(Vector2 center, Vector2 size, float halfExtent, int px, int minThickness)` — 얇은 선반이 사라지지 않게 최소 두께 보장, 텍스처 밖은 클램프.
- `bool IsDiscovered(Vector2 marker, Vector2 me, float meters)`.
- `bool ShowsCheese(RoleId)` / `ShowsShops(RoleId)` / `ShowsOwnStructures(RoleId)` / `ShowsTeammates(RoleId)` — **기획 2절 표를 그대로 함수로.** 팀 쥐는 지금 전부 false지만 **다이얼로 뒤집을 수 있게 함수로 둔다**.
- `float YawToUiAngle(float yawDeg)` — 북 고정 지도 위 화살표 각.

테스트: 원점·네 모서리·범위 밖 클램프 · 최소 두께 · 발견 경계값(정확히 12 m) · 역할표 8칸 전부.

## Task 2 — `MinimapPainter` + CSV

`Assets/Scripts/UI/MinimapPainter.cs` · `Assets/Resources/CSVInfo/BalanceInfo.csv`

- CSV 3키 추가(`MinimapTexturePx` 256 · `MinimapSizePx` 200 · `MinimapDiscoverMeters` 12) → `Tools/CTC/Convert CSV → Info` 실행.
- `Texture2D Paint(MapLayout layout, int px)` — 바닥 `Slot` → 경계 `Groove` → `Rooms`+`Corridors` → `Props` 순으로 `Line`. 손 배치 맵은 `Rooms`가 비어 있고 `Props`만 있다(창고 77개) — **둘 다 같은 코드로 지난다.**
- `FilterMode.Point`, `wrapMode Clamp`, `Apply(false)`.

테스트: 창고 레이아웃을 실제로 불러 칠하고 ⑴ 바닥이 아닌 픽셀이 0이 아니다 ⑵ 텍스처 크기가 CSV 값 ⑶ 방·복도가 빈 손 배치 맵에서도 지형이 그려진다.

## Task 3 — `MinimapMarkers` (Model)

`Assets/Scripts/UI/MinimapMarkers.cs`

- 상점: `ShopSpot.s_All` 등록부를 읽는다(이미 있다).
- 치즈: `CheeseSpot` 전체 → **발견분만** 남기는 클라 전용 `HashSet`. 판마다 초기화.
- 내 구조물: 내 창고·내 요새(소유자가 나인 것만).
- 0.2초 주기 갱신(매 프레임 금지) · R3 스트림으로 View에 넘긴다.
- 역할은 `MinimapLogic.Shows*`로만 판정한다 — 여기서 if를 새로 쓰지 않는다.
