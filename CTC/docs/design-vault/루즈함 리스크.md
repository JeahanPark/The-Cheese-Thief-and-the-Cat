# 루즈함 리스크

교착으로 게임이 늘어지는 상태 — 이 게임의 최대 설계 리스크.

**증폭 요인**: [[시간제한 없음]] + 무적 공간([[임시 피난처]]) + 수동 플레이(회복 기다리기 — [[회복]] 설계에 따라).

**억제 장치**:
- 피난처 수입 0 → 숨음 = 승리 포기 ([[치즈 지점]]·[[무기 티어]] 경유)
- 관통형 입구 2개 → 고양이 대기 = 심리전(루즈가 아니라 긴장)
- 다수 쥐: 고양이가 한 마리를 포위하는 동안 나머지가 범 — 원작의 자기 균형
- **잔여 리스크**: 마지막 쥐 1마리 농성 — 플레이테스트 후 서든데스 검토(백로그)
