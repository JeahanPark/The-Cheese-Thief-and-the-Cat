# 회복 (공백 — 논의중)

[[요새]] 제거로 쥐 회복 수단이 사라짐. 쥐 [[HP]] 100·[[덮치기]] 60이라 스침 1회가 반영구 반피.

**후보**:
- ⓐ 느린 자연 재생 (비전투 5초 후 +2/s)
- ⓑ 상점 회복 아이템 ([[치즈 지갑]] 소모 — 단일 자원 긴장 유지, 원작 감성)
- ⓒ 회복 없음 (긴장 극대화, 원작 시민도 회복 없었음)
- ⚠️ [[임시 피난처]] 내 회복은 존버 유인이라 비추천

**커플링**: 선택에 따라 [[덮치기]] 2방 밸런스·[[루즈함 리스크]](회복 기다리기)가 달라짐
