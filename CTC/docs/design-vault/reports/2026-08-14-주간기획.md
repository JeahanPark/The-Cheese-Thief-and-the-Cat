# 주간 작업 우선순위 (2026-08-14 주)

## 0. 지금 서 있는 자리

| 확정 사실 | 의미 |
|---|---|
| 2:8 봇 배치 파이프라인 완성 | 수치를 돌려 볼 **계측기**가 생겼다 |
| 현행 봇 승률 쥐 **33%** (4/12) | 사람 판의 **하한**. 봇은 심리전·협동 구출·요새 농성을 못 한다 |
| 대형 맵 최장 직선 **20.5m** | 소리 밸런스가 "일을 하기 시작하는" 구간에 겨우 진입 (목표는 12~15m) |
| v3.8·v3.9 전 항목 구현 완료 | 감옥·구출·강아지·상자·쥐 직업·2단계·고양이 전직 — **전부 사람 손을 한 번도 안 탔다** |

> 이번 주의 한 줄: **계측기는 다 만들었는데, 정작 사람이 이 게임을 한 번도 안 해 봤다.**
> 봇으로 더 조이는 건 지금부터 수확 체감이다.

## 1. 후보 3개 (우선순위)

### P1 — 사람 플레이테스트 1세션 (v3.8+v3.9 첫 실사용)

| | |
|---|---|
| **한 줄** | 감옥·구출·상자·직업·전직이 얹힌 판을 사람 4~5명이 처음으로 돌려, 봇 33%가 사람에게서 몇 %인지와 **신규 시스템이 실제로 발동은 하는지**를 잰다 |
| **공수** | 준비 0.5일(항목표·세팅) + 세션 1.5시간(1v4 × 4판) + 정리 0.5일 |
| **선행 게이트** | **P2가 먼저 끝나야 한다** — 아래 참조 |
| **영향 문서** | [[승리 빌드 기획]](검증 방법 표 갱신) · [[v3.8 확장 로드맵]] · [[v3.9 확장 로드맵]] · [[탈락과 관전]] |
| **영향 코드 영역** | 없음(측정만). 관측 지표 수집 지점은 [[코드 다이어그램]]의 통계 계열 — 확정은 client |

**이 세션이 답해야 할 질문은 셋뿐이다.** 늘리면 아무것도 못 잰다.

| # | 질문 | 어긋나면 |
|---|---|---|
| Q1 | **감옥이 "죽으면 할 게 없다"를 실제로 풀었나** — 갇힌 뒤 구출까지의 체감 대기 | 안 풀렸으면 체류 40초·구출 조건이 아니라 *갇힌 동안 할 일*을 새로 설계 |
| Q2 | **2단계(깡패)가 열리는가** — 깡패권을 줍는가, 주워서 임명하는가 | 4판에 0회면 깡패권은 죽은 콘텐츠. 드롭 자리·개수부터 |
| Q3 | **쥐 승률이 봇 33%보다 위인가** — 위여야 정상 | 아래면 봇이 사람보다 잘한 것 → 사람이 못 쓰는 도구가 있다는 뜻 |

**측정 규칙**: 판마다 승자·판 길이·첫 수감 시각·구출 횟수·상자 개봉 수·전직 도달 여부만 적는다.
소감은 판이 **끝난 직후 30초** 안에 받는다(몰아서 받으면 마지막 판 인상만 남는다).

**중단 규칙**: 첫 2판에서 같은 시스템이 두 번 다 발동조차 안 하면, 그 시스템은 그 자리에서
세션 대상에서 뺀다(붙잡고 있으면 나머지 질문을 못 잰다).

### P2 — 기본·확장 맵 시야 차폐 마감 (P1의 게이트)

| | |
|---|---|
| **한 줄** | 대형 맵만 20.5m로 잡혔다. 기본 **28m** · 확장 **36.5m**가 그대로면 사람 판이 열릴 맵이 곧 오염된 맵이다 |
| **공수** | 0.5~1일 (차폐 규칙 자체는 대형에서 이미 나왔고, 작은 방용 대체 배치만 남음) — 구현 공수 확정은 client |
| **목표치** | 두 맵 모두 **22m 이하**. 12~15m 완주는 이번 주 목표가 아니다 |
| **영향 문서** | [[맵 레벨디자인]] · [[승리 빌드 기획]](§넓은 맵의 밀도 문제) · [[v3.8 확장 로드맵]] 1번 |
| **영향 코드 영역** | 맵 생성기의 장애물·벽감 배치 계열 — 대상 클래스는 [[v3.8 확장 로드맵]] 구현 메모 표와 [[코드 다이어그램]] 참조, 확정은 client |

**왜 P1보다 먼저인가**: 사람은 4~5명이라 판은 **기본 맵이나 확장 맵에서 열린다.**
대형 20.5m를 만들기 전 판이 전부 무효였던 것과 똑같은 일이 반복된다 — 시야가 뚫린 맵에서는
발소리 14m·파밍 20m가 아무 일도 하지 않고, 그 판의 소감은 밸런스가 아니라 레이아웃 얘기가 된다.

**기획 측 판정 기준(수치 아님)**: 작은 방에서 차폐를 다 못 채우면 **차폐를 포기하는 대신 방을 잇는
문을 줄이는 쪽**을 택한다. 방마다 물건을 더 쑤셔 넣으면 좁은 방이 통행 불가가 되고, 그건
"숨을 곳이 늘었다"가 아니라 "낄 곳이 없다"가 된다.

### P3 — 낡은 코어 문서 5종 v3 현행화

| | |
|---|---|
| **한 줄** | [[코어 루프]]·[[맵 레벨디자인]]·[[루즈함 리스크]]·[[승패]]·[[탈락과 관전]]이 **아직 v2를 서술**한다 — 폐기된 규칙이 볼트의 정문에 서 있다 |
| **공수** | 0.5일 (배너 + 본문 최소 수정) |
| **영향 문서** | 위 5종 · [[00 기획 그래프 안내]](배너를 달아 뒀다는 서술이 사실과 다름) |
| **영향 코드 영역** | 없음 |

| 문서 | 지금 뭐라고 쓰여 있나 | 실제 (v3.9) |
|---|---|---|
| [[코어 루프]] | "터널 대기 ↔ 치즈 유지비가 등을 떠민다" | 터널 폐기 · 유지비 삭제 |
| [[맵 레벨디자인]] | 쥐 전용 터널 링 · 출입구 9개 | 통로는 양측 통과 |
| [[루즈함 리스크]] | "v2 삼중 장치로 해소" | 장치 2개가 롤백됨 — **리스크가 다시 열려 있다** |
| [[승패]] | 쥐 사망 = 전멸 카운트 | 수감 · 구출 · **2단계** |
| [[탈락과 관전]] | "부활 없음" | 감옥에서 풀려난다 |

**왜 지금인가**: P1에서 처음 이 게임을 만지는 사람이 생긴다. 규칙 설명을 문서에서 뽑는 순간
없는 터널을 찾아다닌다. [[루즈함 리스크]]는 특히 **"해소됨"이라 적힌 채로 사실상 미해결**이라,
P1에서 늘어지는 판이 나와도 "이미 푼 문제"로 착각하고 지나칠 위험이 있다.

## 2. 이번 주에 **하지 않을 것** (안티 골)

| 안 하는 것 | 이유 |
|---|---|
| 봇 승률 추가 조이기 (이속 6.3 · 덮치기 2.8) | 사람 표본 없이 하한만 보고 조이면 **사람 판이 과조정된다.** 곡선은 이미 확인해 뒀으니 P1 뒤에 꺼낸다 |
| 건강검사 ⑦ 이동시간 분모 보정 | 게이트로는 이미 유효하게 작동 중(바닥 게이트 통과). 숫자가 거짓말인 건 맞지만 **이번 주 의사결정에 쓰이는 숫자가 아니다** — P1 뒤 다음 봇 패스 직전에 |
| 시야 12~15m 완주 | 두 맵을 22m로 내리는 것만으로 이번 주 판정에 충분. 완주는 레벨디자인 패스와 함께 |
| v3.9 5번(맵 확장 + 레벨디자인) 착수 | 배치 대상은 다 정해졌지만, **사람이 무엇을 재미없어 하는지** 모르는 채로 넓히면 넓힌 만큼 비게 된다 |

## 3. 최우선 추천 = **P1**, 근거

1. **정보 가치가 압도적으로 크다.** 봇으로 얻을 수 있는 다음 정보는 "33%를 28%로 옮겼다" 수준이지만,
   P1은 *감옥이 배제 문제를 풀었는가* · *2단계가 성립하는가*라는 **되돌릴 수 없는 설계 판정**을 준다.
   틀렸을 때 되돌리는 비용도 지금이 가장 싸다(맵 확장 전).
2. **봇이 못 재는 영역이 지금 게임의 절반이다.** 최근 두 로드맵이 얹은 것은 전부 협동·심리·정치
   (구출·임명·배신 불가·전직 타이밍)인데, 봇은 그중 하나도 못 한다. 33%가 하한인 이유가 곧
   "봇으로는 더 못 잰다"는 뜻이다.
3. **밸런스 조정의 기준선이 없다.** [[승리 빌드 기획]]의 목표치(승률 45~55% · 판 7~9분 · 첫 킬 2~4분)는
   1v4 사람 기준으로 쓰인 값인데, 지금 손에 있는 건 2:8 봇 값뿐이다. 두 축이 만나야 노브를 돌릴 수 있다.

## 4. client 인계 — 시점·방식

**P2만 넘긴다. 지금 바로.** 필요한 건 "기본·확장 두 레이아웃의 최장 직선 22m 이하 + 각 방 통행 유지"라는
목표치 하나이며, 배치 방식·규칙 완화는 전적으로 client 판단에 맡긴다.

완료 판정은 client가 `sightscan` 실측값 2개(기본·확장)를 회신하는 것으로 갈음하고, 그게 도착한
시점에 P1 세션을 잡는다. **P1 준비(항목표·질문 3개·기록 양식)는 그동안 내가 병행**하므로 대기 시간은 없다.
