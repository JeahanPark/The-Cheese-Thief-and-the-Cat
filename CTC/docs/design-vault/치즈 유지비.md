# 치즈 유지비 (v2 신규 — 식량 = 화폐)

쥐는 **10초마다 치즈 −10** 자동 소모. 부족하면 **HP −10 대신 소모(굶주림)**. 시작 치즈 30. 고양이는 없음.

**커플링**:
- [[치즈 지갑]]이 식량+화폐 이중 용도 — 무기냐 생존이냐
- 존버 차단: 터널([[맵 레벨디자인]])에 숨으면 수입 0 → 굶어 죽음 → [[루즈함 리스크]] 해소
- [[회복]] 없음과 결합 — 굶주림 피해도 영구
- 5분 총 300 소모 → [[치즈 지점]] G1 순수익 0, 고등급 가야 흑자 (노출 강제)
