## 공통 접두 (모든 프롬프트 앞에 그대로)

```
Cute stylized low-poly 3D game concept art, night scene, cinematic. One warm amber
lantern pools light on a dark wooden floor; everything outside that pool falls off to
near-black. Palette: deep navy blacks (#0a0f16, #141b27), warm cheese yellow accent
(#ffd84d, #e8b535), muted teal props. Soft shadows, gentle ambient occlusion, no harsh
specular. Simple rounded shapes, low polygon count, hand-painted feel. Cozy but slightly
ominous, playful tension. Camera at a tiny mouse's eye level, 20cm above the floor, so
every piece of furniture towers overhead. No ceiling — only darkness and rough beams above.
NO text, no letters, no words, no logo, no watermark, no signature, no UI, no HUD,
no humans, no photorealism.
```

## 절차

1. Gemini 웹 로그인 → 새 채팅 → 공통 접두 + 1번을 한 메시지로.
2. 톤이 잡히면 같은 채팅에서 2~6번을 이어서.
3. 원본 다운로드 → `docs/design-vault/images/concept-room-<n>.png`.
4. 워터마크(우하단 ✦) 제거는 `tools/store-assets/build_store_assets.py`의 인페인트 단계 재사용.
