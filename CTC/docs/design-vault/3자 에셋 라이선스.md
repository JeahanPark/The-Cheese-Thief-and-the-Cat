> **결론 — 배포를 막는 항목은 0건이다. 지금 위반 중인 것은 1건: 고지 파일이 하나도 없다.**
> MIT·BSD·Apache·Boost·zlib·**Unity Companion License**까지 20여 종이 전부 "사본에 저작권 고지를 포함하라"고

근거 순위는 **① 에셋 폴더 안의 실제 라이선스 파일 → ② 바이너리에서 뽑은 원문 문자열 → ③ 공식 약관 원문**이다.
추측으로 "문제없음"이라고 쓴 칸은 없다. 못 캔 것은 §7에 "확인 못 함"으로 남겼다.

## 3. 파고든 것

### 3-1. Pretendard와 OFL — 결론: **문제없다. 단, RFN이 실재한다**

**RFN이 있다.** 원 저장소 `LICENSE` 첫 줄 원문:

> `Copyright (c) 2021, Kil Hyung-jin (https://github.com/orioncactus/pretendard), with Reserved Font Name 'Pretendard'.`

같은 파일에 파생 원본 3종의 RFN도 함께 실려 있다 — Adobe `'Source'` · `'Inter'` · `'M PLUS 1'`.

폰트 바이너리에서 직접 뽑은 문자열(`Assets/Fonts/Pretendard-Regular.otf`):

> nameID 0 — `Copyright © 2023 Kil Hyung-jin` ⚠ **여기엔 RFN 문구가 없다** (파일 메타데이터와 저장소 LICENSE가 다르다)
> nameID 13 — `This Font Software is licensed under the SIL Open Font License, Version 1.1. This license is available with a FAQ at: http://scripts.sil.org/OFL`
> 트레이드마크 — `Pretendard is a trademark of Kil Hyung-jin; Inter UI and Inter is a trademark of rsms; Source is a trademark of Adobe…`

**우리 빌드가 폰트를 어떻게 담고 있나** (실측):

| 확인 | 결과 |
|---|---|
| SDF 에셋 `m_AtlasPopulationMode` | **1 = Dynamic** |
| SDF 에셋의 런타임 참조 | `m_SourceFontFile: {guid: c24fd1ea…}` = `Pretendard-Regular.otf` |
| `sharedassets0.assets` 안의 `OTTO` 시그니처 | **1건** → **원본 OTF가 통째로 빌드에 들어간다** |
| 같은 파일 안 문자열 | `Copyright … 2023 Kil Hyung-jin` — **저작권 고지가 이미 바이너리에 실려 있다** |
| 참조 범위 | `Game`·`Lobby`·`Room`·`Intro` 4개 씬 + `TMP Settings.asset` |

**조항별 판정** (OFL 1.1 원문이 프로젝트 안에 있다 — `Assets/TextMesh Pro/Fonts/LiberationSans - OFL.txt`):

| 조항 | 요구 | CTC |
|---|---|---|
| 1) *"may not be sold by itself"* | 폰트 단독 판매 금지 | ✅ 게임과 함께 판다 |
| **2) 번들·재배포 시 사본마다 저작권 고지와 이 라이선스를 포함.** *"stand-alone text files, human-readable headers or **in the appropriate machine-readable metadata fields** … as long as those fields can be easily viewed by the user"* | 고지 + 라이선스 | ⚠ **형식상 이미 충족** — OTF `name` 테이블 0·13번이 저작권과 라이선스를 담고 있고, 이게 바로 "machine-readable metadata field"다. 다만 *"easily viewed by the user"*가 게임 플레이어 기준으론 다툼 여지 → **텍스트 파일 하나면 논쟁 종료** |
| 3) Modified Version은 **RFN을 쓰지 마라.** *"only applies to the primary font name as presented to the users"* | 이름 제한 | §3-2 |
| 4) 저작권자 이름을 홍보에 쓰지 마라 | — | ✅ 해당 없음 |
| 5) 폰트는 OFL로만 배포. **"이 요구는 폰트로 만든 문서에는 적용되지 않는다"** | — | ✅ **게임 전체가 OFL이 되지 않는다** |

**SIL 공식 FAQ가 결정적으로 유리하다:**

- **1.4** — *"Can I sell a software package that includes these fonts? Yes … Examples of bundling made possible by the OFL would include: … **games and entertainment software** …"* → 게임 번들을 **이름 대고 허용**한다.
- **1.10** — *"The only situation in which an OFL font can be distributed without the text of the OFL … is when a font is embedded in a document or **bundled within a program**."* → **OFL 전문 동봉은 법적 의무가 아니다**(SIL은 권장만).
- **1.11** — 'embedding'은 *"inclusion of the font … in a way that makes extraction (and redistribution) difficult or clearly discouraged."* → 유니티가 `sharedassets0.assets`로 직렬화한 형태가 여기다.
- **1.3** — *"allow aggregation or bundling with software under restricted licensing"*.

### 3-2. SDF 변환이 RFN에 걸리나 — **회색이지만 위반은 아니다**

FAQ에 비트맵/텍스처 아틀라스를 직접 다룬 항목이 없다. 가장 가까운 두 조항이 **정반대**를 가리킨다.

| 근거 | 방향 | 원문 |
|---|---|---|
| FAQ **1.1.1** | 유리 | *"You remain the author and copyright holder of that newly derived graphic … You are simply **using an open font in the design process**. It is only when you redistribute, bundle or modify **the font itself** that other conditions … have to be respected."* |
| FAQ **2.2 / 2.3** | 불리 | *"**A change in font format normally is considered modification, and Reserved Font Names (RFNs) cannot be used.**"* |

TMP SDF 에셋은 글리프 지오메트리 + 메트릭 + 커닝을 담은 **렌더링 가능한 폰트 자료**라서 1.1.1(단순 그래픽)보다 2.2/2.3(포맷 변환)에 가깝다. 즉 **Modified Version으로 보는 게 안전한 가정**이다.

**그래도 위반은 아니다:**

| 이유 | 근거 |
|---|---|
| RFN 제한은 "**사용자에게 제시되는** primary font name"에만 걸린다 | FAQ **5.3**: *"this applies to the **font menu name** and other mechanisms that specify a font in a document"* |
| `Pretendard-Regular SDF`라는 이름은 플레이어에게 한 번도 안 보인다 | 게임 내 폰트 선택 UI 없음 |
| Dynamic 모드라 **런타임 참조 대상이 무개작 원본 `.otf`** 다 | `m_AtlasPopulationMode: 1` 실측 |

**권고(선택, 저비용)** — TMP 에셋을 `CTC_UIFont_SDF`로 개명하면 논쟁 자체가 사라진다. 참조가 GUID라 배선이 안 깨진다.
**원본 `.otf` 파일명은 절대 바꾸지 않는다** — 그건 Original Version이라 RFN을 그대로 써야 맞다.
소송 리스크가 아니라 **위생 문제**다.

### 3-3. Unity Asset Store EULA — Restricted Assets

> **2.2.2** — *"Restricted Assets have license terms different from other Assets. Those license terms are found in the materials accompanying Restricted Assets ('Restricted Asset Terms') … to the extent Restricted Asset Terms are different from this EULA, **the Restricted Asset Terms will control** … **No other use is licensed or permitted** and END-USER may otherwise not use, reproduce, publicly display, publicly perform, transmit, distribute, sublicense, rent, lease or lend Restricted Assets."*

즉 자산 종류(모델·오디오·스크립트)와 **무관하다.** Unity의 사전 서면 승인을 받아 **개별 에셋에 붙는 딱지**이고, 그 에셋에 동봉된 별도 약관이 EULA를 덮어쓴다. **"Restricted 유형 목록"은 존재하지 않는다.**

**CTC 3종은 셋 다 Restricted가 아니다** — 스토어 페이지가 전부 "Standard Unity Asset Store EULA".

**Restricted ≠ Extension.** 완전히 다른 축이다.

| | Restricted Asset | Extension Asset |
|---|---|---|
| 결정 방식 | Unity 서면 승인 + 동봉 약관 | 스토어 카테고리 (Editor Extension / Scripting / Services) |
| 좌석 | 동봉 약관에 따름 | **1인 1좌석, 최대 2대** (2.3.2) |
| CTC 3종 | ❌ 해당 없음 | ⚠ **셋 다 해당** |

> **2.3.1** *"EXCEPT FOR EXTENSION ASSETS, END-USER is granted a license to install and use Assets on an unlimited number of computers…"*
> **2.3.2** *"…single seat license … only on a maximum of 2 computers … licensed on a **per seat basis and may not be shared or used concurrently on more than 2 different computers**…"* (빌드팜·VM은 예외)
> **2.4** *"any Contractor … **must have license(s) of its own to the Asset**"* — 외주가 붙으면 **양쪽 다** 각자 사야 한다.

**완제품 배포 — 허용되지만 조건이 붙는다:**

> **2.2.1(a)** — *"to incorporate the Asset, **together with substantial, original content not obtained through the Unity Asset Store**, into an electronic application … as an embedded component … **such that the Asset does not comprise a substantial portion of the Licensed Product**"*
> **2.2.1(b)** — *"to reproduce, publicly display, publicly perform, transmit, and distribute the Asset **as incorporated and embedded in that Licensed Product**"*
> **2.2.1(d)** — 인앱 결제 포함 수익화 허용

> **2.2.1.1(b)** — *"may not … **enable a customer or user of a Licensed Product to sell, transfer, distribute, lease, or lend the Assets**"*
> **2.2.1.1(d)** — *"…distribute, transfer, license, sublicense … or otherwise commercialize any Asset **except as expressly permitted in this EULA**"*
> **3.8(iv)** — *"you will not … **remove, obscure, or alter** Unity's or any third party's **copyright notices** … affixed to or contained within … Assets"*

**⚠ 정확히 하자면**: 현행 EULA에 *"유저가 추출 못 하게 하라"*는 **명시적 문장은 없다.**
허락된 배포는 2.2.1(b)의 *"as incorporated and embedded"* 범위뿐이고, 그 밖은 2.2.1.1(d)가 포괄 금지한다.
원본·소스 형태 재배포가 막히는 근거는 **이 두 조항**이지 별도의 anti-extraction 조항이 아니다.
(명시적 추출 금지 문구는 **Omabuarts 자체 라이선스** 쪽에 있다 — 바로 아래.)

**표기 의무 — 없다.** ToS·EULA 전문에 attribution/credit 요구 조항이 **한 줄도 없다.** 3.8(iv)는 반대 방향(이미 들어 있는 고지를 지우지 마라)이다.
