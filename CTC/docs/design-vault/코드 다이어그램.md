```mermaid
flowchart TD

    Dmg --> Dead{HP 0?}
    Dead -->|쥐| Out[PlayerDeath despawn<br/>SpectatorFallback 관전]

    Cheer --> Loop
    Dead -->|아니오| Loop

    Loop --> Dry{전 지점 고갈?}
    Dry -->|예| Revive[최고 등급 1곳 부활 400<br/>판당 1회 = 후반 결전지]

    Loop --> End{쥐 전멸 / 고양이 사망<br/>/ 타이머 600s}

    Result --> Restart[재시작 → 로비]
```

## 물리 레이어 규칙

| 레이어 | 용도 | 충돌 |
|---|---|---|
| 0 Default | 벽·구조물·고양이 | 전부 |
| 2 Ignore Raycast | 바닥 | 설치 판정(`~(1<<2)`)에서 제외 |
| **8 Decoy** | 미끼 | **Mouse와 충돌 끔** (`DecoyLayers`) |
| **9 Mouse** | 쥐 플레이어 | Decoy만 통과, 벽은 막힘 |

`CharacterController`는 `Physics.IgnoreCollision`·`excludeLayers`를 무시하고 **레이어 매트릭스만** 존중한다 — 그래서 레이어를 쓴다.
