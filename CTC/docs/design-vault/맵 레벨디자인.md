# 맵 레벨디자인 (v2 개정의 핵심)

![[맵 시안 v1.svg]]

## 설계 원칙

1. **위험 = 쥐구멍까지의 거리** — 치즈존 등급은 가장 가까운 터널 출입구와의 거리로 결정
2. **외곽 터널 링, 중앙 무방비** — 쥐 전용 터널(물리 크기로 고양이 진입 불가)이 벽·가구 밑을 순환, 출입구 9개(한 곳을 지켜도 우회 가능). 중앙 6·7존은 터널 없음
3. **고양이 순찰 루프** — 중·고등급 존이 자연 순회 동선 위에

## 왕복 리듬 (게임의 심장)

터널 대기 → 치즈존에서 벌기/먹기 → [[치즈 유지비]]가 등을 떠밈 → 고양이 접근 → 가장 가까운 쥐구멍으로 — 반복.
