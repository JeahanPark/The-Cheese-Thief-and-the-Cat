# 임시 피난처 (신규 — 논의중)

가구 밑 낮은 틈 — 물리 높이로 쥐(CC 0.5)만 통과, 고양이(0.9) 차단. **관통형(입구 2개)** + 안에서는 [[치즈 지점]] 수입 0.

**커플링·긴장**:
- [[루즈함 리스크]] — 숨으면 게임이 늘어짐. [[시간제한 없음]]이 증폭
- 존버 방지 논리: 수입 0 → 숨어서는 [[무기 티어]]를 못 사 [[승패]]에 도달 불가
- [[요새]]의 대체재(수동 안전) · [[대시]]와 조합(피난처까지 도주)
- [[맵]]에 3~4개 배치 예정 — 고등급 지점 근처면 리스크 완화, 멀면 무의미

**미결**: 체류 제한(강제 퇴출/HP 감소) 추가 여부 · 안에서 [[회복]] 허용 여부(허용하면 존버 유인 ↑)
