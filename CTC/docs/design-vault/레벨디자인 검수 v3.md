## 2. 등급 = 위험도 정합  ⚠️

위험도 ∝ (피난처 경로거리) × (방 노출/연결). 중앙 R3(Tag2, 출구多)=최고 노출.

- G7(7): R3 남단 (0,−2), 세 출구 모두서 ≈5.7~8, 미로 인접 → **가장 깊고 노출 최대**. ✅
- G6(6): R3 (−2,4), 서통로 입구 2.1 → G7보다 약간 안전 → 6<7 단조. ✅
- G4(4): R7, refuge ≈13 → 고위험 중등급. ✅ (단 G5와 등급차 없이 위험만 큼 → 아래 교환 권고)
- G1·G2·G3(1·2·3): 요새 동실 → 저위험 저수입. ✅
- **G5(5): R4, 요새 F3와 동실 4.95m.** 고수입인데 저위험 → **곡선 역전. 지배전략(안전한 고수입 파밍) 유발.** ❌

원인: 활성 레이아웃 6방 중 4방(R2·R5·R4·R1)에 요새가 들어가 "요새 없는 위험한 중간방"이 R7 하나뿐. 풀은 R4를 4~5, R7을 4~5로 허용하는데 레이아웃이 grade5를 **요새방 R4**에 얹음. → 교환으로 해소(권고표 A).

## 3. 요새 커버리지  ❌

**분산** (사분면)
| 방위 | 요새 | · | 방위 | 요새 |
|------|------|---|------|------|
| 남서 | F0 | | 북동 | F1 |
| 서 | F2 | | 동 | F3 |
| 북서 | 없음 | | 남중앙 | 없음 |

- 동서 균형은 OK(서 F0·F2 / 동 F1·F3).
- **개수 부족**: 활성 4개 vs 스펙 §12-A "요새자리 6개" vs 게임규칙 "초기 쥐당 1개"(최대 쥐 6). **5~6인 매치 시 스폰 벙커 부족.** 풀엔 7슬롯 있으나 그 중 R6·R8·R9 슬롯은 해당 방이 레이아웃에 미포함 → 실제 배치 가능한 건 4개뿐(R5·R1·R2·R4). 요새 6개를 채우려면 방 2개 추가 필요(권고표 D와 동일 해법).
- **공백대**: 북서(R6 미포함으로 빈 사분면)·남중앙(미로 死공간)엔 치즈도 없어 커버 부재 자체는 무해하나, 미로가 무보상임을 방증(항목4).
- **한 요새 파괴 시 대안**: 동편은 루프(R3-R4-R1-R7)라 F3 파괴돼도 F1로 우회(≈11) ✅. **서편은 F0 파괴 시 R5→R2 L통로(≈15)만 남아 취약**(항목4).

## 4. 길목 / 우회 구조  ⚠️

**연결 그래프**
```
        R7 ── R1
        │      │
  R2 ── R3 ── R4
  │      │(미로A 死)  (미로B 死)
  R5   [출구없음 남]
```
- **동/북편 = 루프**: R3-R4-R1-R7-R3 순환 → 쥐 순환·고양이 완전봉쇄 불가. ✅ 견고.
- **서편 = 단일 체인**: R3—R2—R5가 외길. R2·R5는 각자 진출로 1개. 고양이가 R3-R2 통로(−3.5..−10.5, y2.5)를 캠프하면 **서편 wing(R2·R5·F0·F2·G1·G3) 전체가 중앙/동편과 단절**. **F0=시작·QA앵커 요새**이므로 서편 스폰 쥐의 유일 동맥이 봉쇄 취약. ❌ 동편 대비 비대칭.
- **미로 오펀**: MazeA(ExclusiveRoom R9)·MazeB(R8)의 **종착 방 R9·R8이 레이아웃 미포함** → 두 미로 모두 방·치즈·요새 없는 **막다른 무보상 리스크 지대**. R3/R4 남단에 매달린 死appendage. 쥐가 들어갈 이유 없음(공간 낭비) 또는 몰릴 시 무의미한 함정. LD 원칙6(위험=보상) 위배. R8·R9를 포함하면 미로 종착 보상 + 요새 2개(R8 (12,−11)/R9 (0,−12.3)) 동시 해결(권고표 D).
- **통로 폭**: 전 세그 1.6 ≥ 고양이 실효 0.86 → 통과 가능 ✅. 요새 입구 1.0×0.75 < 0.86 → 고양이 진입 불가(쥐 전용) ✅ 정합.
