## 2. 짧은 설명 (Short Description)

스토어 상단·검색 결과·위시리스트에 뜬다. 밸브 권장 **최대 300자**.

**한국어**
```
치즈를 훔치는 쥐들, 그리고 그중 하나를 노리는 고양이 한 마리. 시작할 때 고양이는 무작위로 정해집니다. 쥐는 어둠 속에서 치즈를 옮겨 요새를 짓고, 고양이는 발소리를 쫓습니다. 최대 10인 비대칭 멀티플레이 숨바꼭질.
```

**English**
```
Mice steal cheese in the dark. One cat hunts them. The cat is drawn at random when the match begins — nobody knows who until it's revealed. Haul cheese, build cheese forts, and listen for footsteps. Asymmetric multiplayer hide-and-seek for up to 10.
```

## 3. 자세한 설명 (About This Game)

**한국어**
```
[h2]한 마리가 고양이가 된다[/h2]
대기실에 모인 사람들 중 고양이 한 마리를 서버가 무작위로 뽑습니다. 시작 직전에 전원에게 공개됩니다.
나머지는 전부 쥐입니다.

[h2]쥐 — 벌고 빠진다[/h2]
어두운 창고에서 치즈를 퍼 나릅니다. 모은 치즈로 새총과 기관총을 사고, 요새를 세워 몸을 숨기고,
창고를 지어 치즈가 알아서 쌓이게 합니다. 벽을 부수면 그 뒤에 상자가 있고, 상자 안에는 직업권이 있습니다.

[h2]고양이 — 찾고 덮친다[/h2]
쥐는 소리를 냅니다. 뛰면 발소리가 멀리 가고, 웅크리면 좁게 갑니다. 치즈를 캐는 소리도 들립니다.
덮치기 한 번이 판을 뒤집습니다.

[h2]맵[/h2]
30×30m부터 120×120m까지 세 종류. 방장이 고릅니다. 지형은 판마다 새로 생성됩니다.

[h2]지금 상태[/h2]
개인 개발 중인 게임입니다. 한국어만 지원하며, 온라인 멀티플레이 전용입니다 —
[b]혼자서는 플레이할 수 없습니다.[/b]
```

**English**
```
[h2]One of you is the cat[/h2]
When the match starts, the server draws one player at random to be the cat, and reveals it to everyone.
Everyone else is a mouse.

[h2]Mice — earn and slip away[/h2]
Haul cheese through a dark warehouse. Spend it on slingshots and machine guns, raise cheese forts to hide
behind, and build storehouses that stack cheese for you. Break a wall and you'll find a crate behind it.

[h2]Cat — listen and pounce[/h2]
Mice make noise. Running carries far, crouching carries close, and mining cheese is audible.
One pounce turns the match around.

[h2]Maps[/h2]
Three sizes, from 30×30m to 120×120m. The host picks. Layouts are generated fresh each match.

[h2]Where this is at[/h2]
A solo-developed game. Korean language only, and online multiplayer only —
[b]there is no single-player mode.[/b]
```
