스팀 매칭 A · 이번 수정의 핵심

지난 테스트는 양방향 모두 접속이 안 됐고(릴레이 예열·타임아웃 수정), 상대 화면에 NRE가 폭주했다(스팀 수명 수정). 이번엔 그 둘이 잡혔는지를 본다.

A-1
기기1: 방 이름 넣고 방 만들기 (공개)
로그 "[SteamLobby] 방 생성: …" · 화면 Mode: Host (Steam) · Players: 1
A-2
기기2: 방 목록 새로고침
방 이름 (1/9) 버튼이 목록에 뜬다
안 뜨면 5초 뒤 한 번 더 — 스팀 목록 반영이 느릴 때가 있다
A-3
기기2: 방 버튼 눌러 참여
양쪽 로그에 Connecting with … → Connected with … (이번에 Normal로 올린 새 로그) · 기기2 화면 Mode: Client (Steam) · 기기1 Players: 2
Connecting만 뜨고 Connected가 안 오면(25초) → NAT 문제로 확정 — B-3으로 로그부터 보내 두기
A-4
역할 고르고(고양이 1 · 쥐 1) 게임 시작 → 1~2분 플레이
서로의 캐릭터가 보이고 움직임이 자연스럽다 · 발소리 표식 · 치즈 채굴 동작
A-5
채팅(Enter) 양방향 한 줄씩
서로의 줄이 보인다
A-6
기기2: Disconnect → 다시 방 목록 새로고침
목록이 정상으로 뜬다 · 에러 폭주 없음 — 지난번 GetData NRE가 터지던 바로 그 지점
A-7
기기2: 같은 방에 재참여
다시 Connected · Players: 2
A-8
기기1(호스트): Disconnect → 방 만들기 다시
새 방이 서고 기기2 목록에 다시 보인다 — 호스트 쪽 스팀 생존 확인
A-9
양쪽 게임 정상 종료 후 Player.log 끝부분 확인
NullReferenceException 없음 (경로: %USERPROFILE%\AppData\LocalLow\DefaultCompany\CTC)

로그 명령 · 예약어 B · 개발 빌드 전용

클라 로그를 메신저로 나르지 않기 위한 기능. 매치 중(A-4 상태)에 한다.

B-1
채팅 열고 / 한 글자
입력창 아래 힌트: /send log 내 로그 파일을 호스트에게 보낸다
B-2
/se까지 쳐 보고 → 지우고 일반 글자
/se에선 힌트 유지 · 일반 글자에선 사라짐
B-3
기기2(클라)에서 /send log 입력 후 Enter
내 화면 "보내는 중… 512KB (N조각)" → 곧 전원 화면에 "[로그] 도착 NKB → ClientLogs/…"
B-4
기기1(호스트) PC에서 …\LocalLow\DefaultCompany\CTC\ClientLogs\ 폴더 열기
방금 파일이 있고 메모장으로 열면 기기2의 로그가 읽힌다
B-5
바로 이어서 한 번 더 /send log
"잠깐 — N초 뒤에 다시" (15초 쿨다운)
B-6
모르는 명령 /abc 전송
명령이 아니라 그냥 채팅으로 나간다 (상대 화면에 /abc)

첫 사람 플레이테스트 D · P1

계측기는 다 있는데 사람이 이 게임을 한 번도 안 해 봤다. 제대로 한 판(가능하면 두세 판) 하고, 아래 세 질문에만 답을 적는다 — 이 답이 다음 밸런스·기획 방향을 정한다.

D-1
잡히면 즉시 탈락(감옥 없음) — 판이 너무 빨리 끝나나? 죽고 나서 관전이 지루한가?
D-2
2단계가 열렸나 — 벽을 부수고 깡패권을 주웠나? 임명(F)을 썼나? 고양이가 죽었을 때 2단계로 갔나?
D-3
쥐 승률 체감 — 봇 하한이 37%다. 사람 쥐는 그보다 잘 사나? 요새를 몇 번 세웠고 몇 번 살았나? 고양이는 전직까지 갔나?

기록은 여기 적고 스크린샷으로 남기거나 그대로 불러 줘 — 페이지를 닫으면 입력은 사라진다.

버그를 만나면: 그 자리에서 클라가 /send log → 호스트 ClientLogs/ 파일과 함께 상황 한 줄이면 된다.
