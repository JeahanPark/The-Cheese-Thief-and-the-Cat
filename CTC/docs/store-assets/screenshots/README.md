합성 이미지나 캡슐 아트는 스크린샷 칸에 올리면 안 된다.

## 왜 인게임을 못 쓰나

맵 지오메트리가 아직 **Gridbox 프로토타입 머티리얼**이다. 벽에 `PROTOTYPE 1×1 METER`라는
글자가 그대로 찍혀 있다. 프롭(요새·벽감·상자·치즈)은 텍스처가 붙었지만 **맵 자체가 회색 박스**라,
이대로 스토어에 올리면 그레이박스 데모로 읽힌다.

**막힌 것은 촬영이 아니라 맵 아트다.** 벽·바닥 머티리얼을 프롭과 같은 경로로 교체하면
(`Tools/CTC/Apply Prop Textures`와 같은 방식) 그때 다시 찍으면 된다.

## 찍는 법

게임 뷰를 1920×1080으로 두고 플레이 중 `Tools/CTC/…` 없이 그냥 캡처하거나,
MCP `u_screenshot`을 쓰면 프로젝트 루트에 `screenshot.png`로 떨어진다.
